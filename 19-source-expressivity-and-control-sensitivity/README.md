# Source Expressivity and Control Sensitivity of Ordinal Assignments

**18-page explanatory manuscript, 17 November 2026.**
[Read the paper](paper.pdf) · [LaTeX source](paper.tex) · [Sources and scope](SOURCES.md)

The paper collects the source-representation results that are independent of
the permitted-control decision proof. Its Boolean compiler turns finite
systems of actual source observations into one unconditional ground weak or
strict comparison while preserving every shared witness. Absolute scalar
observers handle functional outputs; linear source equations eliminate common
all-one observations of functional variables without assuming an all-one term.

An explicitly restricted grammar supports arbitrary nested ground binders and
opaque higher-type source blocks. Its carrier construction pays the original
finite box budget and defines the entire genuine head graph, including all
finite-prefix inputs. The reserve proof is valid for every admitted literal
bracketing policy. An active functional-argument example states the grammar's
actual boundary.

For every finite prefix, a single fixed permitted primitive recursive control
agrees with G on that prefix and differs by at most one everywhere, yet makes
ground weak and strict comparison Pi^0_1-complete. This concerns that new
control, not the unchanged G. Short diagnostic results explain computable
countervaluation bounds and complete-count residue attainment for supplied
actual unary sources. An appendix computes the policy-dependent 204/184
example directly.

The functional-input hardness proof already in the main numerical paper,
including its unchanged-standard-control corollary, is not duplicated.
This companion retains the other useful content of entry 09
and the source diagnostics of entry 05.

## Build and verification

Run `python3 build_pdf.py` in this directory with Python 3 and a standard
TeX Live or MiKTeX installation. The script uses pdfLaTeX and, when a
BibTeX file is present, BibTeX; it downloads nothing. All mathematical
source inputs required to rebuild this PDF are included. Companion proofs
are cited conventionally with their exact imported interfaces stated.

[VERIFICATION.json](VERIFICATION.json) records the exact PDF, clean build,
isolated rebuild and page inspection. `SHA256SUMS` identifies this edition;
PDF metadata may make a later build's byte hash differ. The document checks
and AI-assisted hand review are not independent human verification, a
completed proof-assistant port, or a priority assessment. The repository's
formal target register remains authoritative for its older checked objects.
