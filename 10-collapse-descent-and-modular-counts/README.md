# Controlled ordinal descents, restricted partitions and Cartier observers

[Paper PDF](paper.pdf) · [TeX](paper.tex) · [Source guide](SOURCES.md)

The paper proves a congruent-growing-budget transfer for polynomial ordinal
blocks, derives the actual moving-prefix partition coefficient, constructs
its complete binary observer, and proves the exact primitive-root residue
tuple period on genuine linked inputs. Full-state periods and selected
scalar observations are kept separate; the remaining parity and canonical
comparison questions stay open.

Build locally with `python3 build_pdf.py`. The directory supplies all TeX
inputs; only standard cached Tectonic packages are needed. Computer Modern
is selected explicitly. Mathematical dependencies on the included foundations
companion and published background are named in the text.
