# Actual-Source Arithmetic and Undecidability Boundaries

[Read the paper](paper.pdf) · [TeX source](paper.tex)

The paper turns existential arithmetic of supplied actual Gödel-T sources into
one universal canonical comparison, while preserving every shared input. It
then separates two undecidability boundaries from the remaining ground-input,
unchanged-control problem.

The full local arguments cover:

- Addition, constants, sorting, Boolean truth bits, collision detection and
  conjunction, with a polynomial bound on added source DAG size.
- Absolute scalar observation for functional-output sources and a computable
  decision equivalence for the complete all-ground-free-variable domain.
- Elimination of functional unit observations, actual unary carriers and the
  reserve induction for a complete grammar with nested ground binders.
- Construction at the original finite box budget and consumption of a paid
  certificate into the entire original head graph, including finite exceptions.
- Undecidability at the unchanged control when functional free inputs are
  allowed: finitely many queries at internal level two, or one query at level
  three using an actual closed projection-kernel constant.
- Ground-only comparison hardness after a fixed primitive recursive
  additive-one control perturbation, agreeing with the original control on
  any prescribed finite prefix.

The control perturbation is fixed before a program index is supplied. It does
not prove hardness for the unchanged control. The source construction allows
arbitrary nested ground binders but does not cover unrestricted active
functional-argument application. The finite-query and single-query results
retain their different internal type bounds.

The [foundations companion](../05-wilken-weiermann-foundations/README.md)
contains the canonical clauses, norm estimates and evaluator used here. The
published polynomial-semiring undecidability theorem is cited conventionally;
all new source interpretations and bridge arguments are printed in this paper.
No private source file or project notation is needed to follow its proofs.
