# Uniform original vertex and concrete parameterized paths

The ten frozen targets extend the supporting application-closure chain for
paper 06 `lem:id1`. They retain the original definitions in
`ApplicationCertificateLiftPathDefinitions`: `vertex` is the original decoded
application with its zero fallback; `liftEntries` maps each original entry to
that vertex and the original `ApplicationCertificateLiftEdge.liftEdge`;
`liftPath` uses the original path decoder and encoder. The semantic source
counterpart is `ApplicationCertificateLiftPathTargets.ActualOriginalPositiveLift`,
proved in `ApplicationCertificateLiftPathProof`. This packet does not identify
that external semantic theorem with an internal derivation.

## Program choice and calibration

One `oldVertex : Program 5` is selected after the ranked signature and before
every finite source window, table, and ambient Gamma. Inputs are exactly
`[parameter, domain, codomain, RAWargument, value]`. The original Object decoder
reads `pair(right(parameter), value)`; its Gamma and original payload feed
the original vertex, with `left(parameter)` as the original context code.
Malformed Object decoding returns zero. Global all-input calibration and the
original parameter codec establish every encoded source slice, including
malformed or rejected domain, codomain, argument, and value inputs.

The dispatched vertex tests the two actual canonical typed predicates at the
same parameter. Its active branch is the existing parameterized `actualJ`
at `[domain, codomain, value, RAWargument, parameter]`; `actualJ` retains its
internal normalization of the argument. Its inactive branch is the complete
`oldVertex` on the unchanged five-vector. Calibration at subtype-closed source
slices covers both branches and every natural path certificate. The mapper is
the existing `InternalApplicationPathMap.pathMap`, with no certificate, fuel,
entry representation, or edge transformer changed.

## Internal scope

Activation factors are the selected function and argument typed graphs under
the original `consCode` arrow graph. The concrete path invariant is activation
and actual codomain membership at the same parameter. The invariant contains
no path checker, computability predicate, normalization fixedness premise,
semantic calibration field, or stored preservation law.

The quotient edge is the literal checker from
`InternalParameterizedQuotientEdgeChecker`. Its typed propagation establishes
invariant preservation. The same-edge canonical application rule from
`InternalParameterizedCanonicalQuotientEdgeApplicationLift` establishes the
existing path API's exact single-edge compatibility obligation after exposing
the actual arrow constructor output internally. Both supplied vertex outputs
and the original `edgeLift` output remain explicit graph witnesses.

The reflexive and positive path targets specialize the already proved
`InternalParameterizedApplicationPathLift` to those concrete programs. Local
invariant preservation and edge compatibility are proved conclusions, not
premises of the specialized targets. The starting invariant, original checker
acceptance, both actual vertex outputs, and actual mapped certificate remain
explicit graph inputs. All parameters and value terms are symbolic in an
arbitrary original calculus body and derivation context.

At closed original source types, the final target derives the initial invariant
for the same normalized Data from source/argument typing and the actual graph
`parameter = pair(contextCode, gammaCode)`. The Gamma code remains symbolic;
the accepted normalized membership slice derives codomain membership without
an added membership or successful-decoding premise.

The outer original Object decoding, internally bound shared runtime Gamma,
application-result wrapping, and outer `pathValue` assembly still need to be
connected to the unqualified `CertifiedApplicationLift` antecedent. No fixed
object fiber is inferred from that antecedent. The numbered `lem:id1`, its

supporting targets.
