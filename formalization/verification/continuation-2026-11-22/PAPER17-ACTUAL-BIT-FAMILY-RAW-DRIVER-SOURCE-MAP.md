# P17: finite raw frontiers conditional on exact high compilation

Printed source: `arithmetic.tex`, `thm:arithmetic`, the dimension decrease in
the finite raw-coordinate recursion, not a construction of the high codec.

* A sufficient bound program must dominate the exact named typed threshold on
  every nonzero-dimensional encoded family. The high callback is explicitly
  required to return the literal encoded ordered list of the actual high
  residuals at that same bound. Neither program is implemented or assumed
  correct by syntax or by this package alone.
* Raw low scans use the actual sorted distinct names and one shared digit
  per branch. Their exact low transport preserves the signed test and wanted
  bit and never mistakes an undefined or missed source read for a false bit.
  At zero depth the first separate closed evaluator is used and no callback
  is consulted. Every raw frontier is the literal encoding of its typed
  frontier, preserving positions.
* Preservation of satisfiability uses genuine paid high semantics only
  through supplied exact high calibration at a common bound. Every remaining
  frontier family shrinks actual union-coordinate dimension by a step, so
  after original dimension plus one scans no family remains. The propagated
  Boolean exactly records existential satisfiability for the original
  typed family. No arbitrary raw code validation or arbitrary block theorem.
* The raw scanner is computable from computable control, sufficient-bound
  program and high callback. This is composition and finite iteration only,
  not a claim that the missing exact high callback has been implemented.
