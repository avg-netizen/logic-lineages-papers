# Paper 16: actual header to original ordered field witnesses

Frozen exact targets and initial proofs, native gates pending. The
open root takes the genuine original nodeGood header selected with the
actual literal tag and requested finite arity. It opens each original
field selector in order: start with cellTail, read cellHead of that
cursor, then use the actual cellTail composition for the next cursor.
These are exactly the original path envelope field ASTs, not a
separate parser or assumed opaque nodeFields output. The proof performs
finitely many genuine object graph cuts and handles their capture-free
renamings; the ambient object conclusion may use those witnesses under
the binders without letting fresh variables escape.

The actual finite list of OTerm witnesses has the requested length.
Retain all the actual selector reports at the same original q. The
existing readNode supplier combines them with the same actual header
and genuine literal-tag evaluation to give the original sparse
equation q = rawCons(tag,packedBody(fields)). The guard is needed for
the packing equation and actual structural use; totality of selectors
alone would also produce (possibly default) values for malformed inputs.
No separately supplied parser graph or native reflection is used.

The independent numeric alias concerns the same actual AST:
output one iff original unpackNode succeeds at exactly the literal tag
and fields of that arity, on all raw inputs. This includes malformed,
noncanonical and empty input rejection where the source parser fails.
This does not show that an unchanged V graph reveals an AST, that
arbitrary recursive child/types/arguments are valid, that their
measurements are correlated, or that the printed protected/fresh-port
context obligations are paid. The open rule applies to all actual
headers, in particular lambda tag 2/2 and auxiliary tag 6/4.
