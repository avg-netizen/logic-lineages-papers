literal packNode 4 [h,a], with no assumption that a is empty, and no
change to the tag or argument codec. Use the selected ordinary layer at
original slots 0/4 of [H,K,IDs,prior terms,prior args]. Actual H and
argument hits go through the existing Cartesian constructor. The same
key is retained by right append through throughOrdinary, then left
through nonAuxPart and termsPart. No numbered branch or alternate raw
head is selected.

at its own coordinates with exactly the same H/K. It uses just the
argument inclusion projection of the checked cross-bound reports, to
one real parent predecessor. The actual selected successor and its
literal range expose its original ordinary layer on those same
predecessor arguments. The scratch root obtains both original
observations, installs that exact parent term list at the supplied

supplied physical scratch on the same ordinary parent key.

in an actual selected args list, both original weak object comparisons

original scratch. This is not a provenance theorem for those argument
or measure reports, not general own-cover, and not an assertion about
a numbered head. The original nullary case independently derives the
argument zero hit; this generalized theorem does not prove it anew.
