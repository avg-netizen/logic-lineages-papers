# Paper 16: composition of genuine object inclusions

The existing calculus formula `axisInclusion` universally quantifies
membership of the same scratch key in two actual lists. Bind that key in
the calculus, use the two original inclusion derivations successively at
the same unchanged intermediate list, and universally quantify it again.
The pair result composes term and argument inclusions independently
on exactly the same intermediate observations.

This is a compositional rule, not a proof that a grammar step has an
inclusion. It asserts no numerical reflection, adjacent-depth result or
transport for arbitrary depth changes.
