The exact rule compares two genuine child grammar observations at their
own (depth, numeral) bounds to a genuinely observed parent predecessor
at (d,M), with both physically reported child occurrences. Each child
has both genuine weak bound relations to that same predecessor. The
checked chosen cross-bound result gives an actual term-axis inclusion
for each child report into the same predecessor scratch, then that
inclusion is instantiated at each unchanged original child key.

The actual parent successor is at (suc d,M) on the same H,K. True
range(suc M) from original program totality and actual recursive split
give the corresponding real successor term-part report, with the actual
predecessor as its child tape. The final term-part append is opened
by original composition cases: the right row is the original actual
auxApplications selected on [K,predecessorTerms]. Use two supplied
actual K members, both real predecessor component occurrences, original
auxiliary introduction, and original append-from-right on the same
literal auxiliaryTerm tag-six key.

This does not prove availability of both child own-cover reports for an
arbitrary term, infer measurement/typing/derivation provenance from a
number, or identify an older opaque generator. Separate option source
and least/decision obligations are unaffected.
