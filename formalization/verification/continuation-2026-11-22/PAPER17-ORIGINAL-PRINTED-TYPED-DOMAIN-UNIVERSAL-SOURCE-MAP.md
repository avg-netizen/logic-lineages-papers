# Paper 17: actual successful-domain universal counterpart on the original typed circuit

Printed source: `arithmetic.tex`, `thm:arithmetic`, absence of an existential
counterexample **on the same original domain**.

- A baseline is defined exactly when the actual original evaluator has
  a genuine successful Boolean observation. Neither invalid nor miss
  is a value in this domain. For a fixed requested polarity, a
  counterexample is `.ok` of exactly the opposite Boolean.
- Use the actual existing typed noncomputable original existential
  result at the opposite polarity. Its false branch proves all defined
  original baselines yield the requested successful Boolean. Its true
  branch supplies an actual contrary observation.
- The separate unrestricted universal version requires explicit actual
  total definedness at **every** baseline. Topology, plain terminal
  admissibility and selected control remain as in the original typed
  existential; they are not used to infer total domain.
- This is one universal block on the stated actual successful domain or
  explicit total input, not intermediate quantifier elimination,
  arbitrary mixed quantifier nesting, or raw effectivity.
