# Exact numeric terminal for the literal original signed row formula

Paper 17, `17-permitted-control-canonical-comparison/sections/arithmetic.tex`, lines 3–19 and 33–54. The exact checked #1029 numeric circuit driver feeds the original same finite bank to the #1015 admitted literal named-row suffix.

- The raw guard checks all original variable occurrences against capacity and requires **every** summand to have the variable tag, including signed zero or repeated occurrences. It does not use the wider plain-phi predicate. The numeric evaluator substitutes actual bank values into literal rows via the existing exact substitution code and uses the existing ground evaluator on the result. This is not a search over assignments, and preserves signed divisibility, inequality and Boolean positions.
- A raw gate failure is returned before the terminal gate, with the same code. Unsupported/raw out-of-range suffix produces 0 only on a successful bank. For an admitted typed suffix and original topological bank fit, exact composition calibrates to #1015 terminal observation; true and false are distinct codes 5 and 4, both separate from rejected gate/test or parser result codes. A true/false answer does not create a graph on a failed run.
- Terminal data routines are primitive recursive; the complete raw run remains only Computable under Computable f. The existing bounded-source codec is a separate scope: it can evaluate finite admitted source tests with shadowing, but must derive a separate raw exact test-name guard before using this bank interface. No unbounded quantified decision, cutoff, or circuit parser is claimed.
