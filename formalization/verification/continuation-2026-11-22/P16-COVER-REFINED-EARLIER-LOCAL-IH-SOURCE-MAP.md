# Paper 16: actual earlier local IHs for refined lambda and auxiliary own-cover

Frozen draft; native gates pending. Generic exact
`exact_OpenCoverOwnEarlierLocalIH`, then instantiated literal block
`exact_OpenCoverRefinedLambdaOwnEarlier` and
`exact_OpenCoverRefinedAuxOwnEarlier`.

The actual original object induction motive is indexed by raw key q:
positive actual refined V at q implies the quantified typed own-key
property of the original refined scratch. The bounded formula uses the
literal existing `InternalStrongInduction.below`; it quantifies strictly
smaller raw terms, not depth or a meta-level Nat. The property at one
raw key uses the original finite universal block for context, type and
scratch result, in order. Its matrix is exactly the existing local
typed-window / scratch / member clause.

Actual below specialization consumes a genuine `ltF child parent`
and actual positive child V. It selects that smaller object's finite
universal body, instantiates the supplied context and type and a fresh
scratch output, and introduces that single output quantifier to obtain
the original local IH. It does not infer a typed report or scratch
existence from the earlier assumption. No external well-foundedness,
closed numeric transport or opaque predicate calculus is used.

The literal lambda and auxiliary links obtain exact earlier relations
from their original physical code constructors and actual child
acceptance from the checked same refined unary program, then replace
their previously explicit local IH premises with one original below
derivation at the parent's raw key. They continue on the exact same
V⋄/M⋆ original scratch. The lambda body W remains an independent actual
input. Auxiliary typed children are provided by strict W at the same
context, not a protected fresh-port extension. Actual K membership
and parent validity/measurement/scratch reports remain explicit.

This is two genuine local induction links, not a full strong-induction
instance for the cover: a complete arbitrary-key progress derivation
still needs all physical branch contracts after ordered raw-header
elimination. In particular, ordinary/numbered arguments need their
proper original argument scope and the protected/typed context domain
does not follow from raw syntax. Unchanged older V/W and the printed
ambient/fresh proof are not asserted.
