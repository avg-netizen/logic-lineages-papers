# Paper 16: numeric transport across the original grammar bounds

The original `NumberedWindowCoverAlgorithm.grammar` recursively returns a pair: the actual term list and the actual argument list. The proof keeps head and type lists fixed and uses their exact leaf, lambda, ordinary, numbered, application, and argument-cell constructors. An increase in maximum numeral enlarges the ID range. A successor in depth uses inclusion of both preceding lists, beginning with empty terms and the empty argument code. The two increases compose in the same direction.

This establishes membership inclusion for both numeric output lists. It preserves the raw code and uses the original grammar; it does not equate lists, guarantee multiplicities, transport an arbitrary open object-derivation graph, supply the child bounds from an actual parent measure, or prove unconditional own-cover membership.
