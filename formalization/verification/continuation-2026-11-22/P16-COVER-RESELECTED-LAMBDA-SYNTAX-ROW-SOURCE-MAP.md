# Paper 16: literal lambda-recursive syntax through the actual earlier table

Frozen independent exact targets and initial split proofs; native gates
pending. This is a new explicitly selected lambda-only row implementation,
not a changed or reflected original V. Its exact physical scratch step
takes [prior,old,0,0]; currentKey is successor of prior. On literal
tag-2/arity-2 header and actual earlier-body test, it reads the annotation
at field 0 using selected T, and reads the body bit at field 1 using the
exact physical earlier table/offset. Both have to equal one. Every
other raw input goes to the supplied V at the same current raw key.
The unary wrapper is the actual existing scratchRow selected reader
with the same two zero parameters, not an independently evaluated child.

Numeric split is conditional precisely on established original
TermSyntaxCalibrated V and a separate exact TypeSyntaxCalibrated T for
source typeBit (not a finite settings carrier guard). The literal
lambda row uses actual unpackNode, both real field selectors, strict
earlier key, calibrated lookup and checked original recursive bit
(1795353604930716047-72). The all-input wrapper establishes the lookup
premise by strong induction on the original scratchRow table. These
two numeric claims have no object-graph consequences by reflection.

The open literal row starts with the actual same-R prior table and
actual accepted R update on that exact tape, not with a supplied
child bit. It reconstructs the same physical header, both field
reports and strict earlier arithmetic at the literal lambda key.
A genuine child read at the earlier key is obtained by original

via the accepted thin same-table lookup with the selected update's
actual accepting lookup. Original graph functionality transports
that same child read to one. The output gives actual T=1, actual
selected recursive child=1, and the actual lookup=1 on the same
prior table. No native hypotheses are used in the open proof.
