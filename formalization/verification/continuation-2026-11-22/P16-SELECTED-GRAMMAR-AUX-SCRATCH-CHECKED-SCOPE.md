# P16 conditional auxiliary own-cover in the actual chosen scratch

The frozen targets and original reading are in the adjacent
P16-SELECTED-GRAMMAR-AUX-SCRATCH-SOURCE-MAP.md. That map pins the initial
editions. The adjacent Observed repair and Membership precheck manifests
explain the binder-only adjustments. The native receipts pin the tested
editions rather than the initial editions.

The Observed gate returns the actual chosen option with the observed
successor vertices as payload, the same physical scratch value, and
membership of the literal auxiliary parent. The Membership gate instead
starts from a supplied actual scratch report and uses functionality to
obtain membership in its exact output; it does not require the caller to
supply the parent stage observations.

Both assume actual child stage observations and occurrences, four child
bound reports, both actual type occurrences, and actual parent validity,
measurement, and measure-code reports. Neither derives these inputs from
an arbitrary term, claims unconditional own-cover, or proves a numbered
statement.
