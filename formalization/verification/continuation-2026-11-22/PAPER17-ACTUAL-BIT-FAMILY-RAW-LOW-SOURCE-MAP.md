# Paper 17: code for reusable low strips on ordered signed-bit families

Printed source: `arithmetic.tex`, finite matrix language and residues,
finite strips, and one-variable projection in `thm:arithmetic`.

- Apply the existing exact three-status encoded field slice to each
  original row at the same literal digit across the family. Invalid and
  genuine missed reads reject the entire selected clause. For all hits,
  retain exactly the original test and wanted bit with its own residual
  constant and ordered surviving operands, including genuine zero
  coefficients. All-hit empty rows and clauses retain their distinct
  role. No numerical code default produces a Boolean row.
- Close the program on the same raw family: return exactly one encoded
  residual family for each digit in the original range, keeping order
  and allowing duplicate and empty children. Show raw clause, family,
  and strip programs computable given the selected numerical control as
  a computable function. This does not inspect arbitrary valuations or
  do a bounded valuation-bank scan.
- On literal encodings prove exact ordered functional agreement with
  the corresponding typed low strips. The measured raw namespace of
  each returned child is contained in the original names with this
  actual chosen name erased, and strictly shrinks for any true used
  source name. The source namespace is the union over original literal
  occurrences, not the nonzero coefficient support.
- No raw-input validation, raw high compiler, one closed-block Boolean
  decision program, or promotion of the printed theorem. The typed
  semantic equivalence to an unbounded low strip is a prior theorem;
  this candidate supplies the missing code agreement and strict raw
  re-entry measurement for the low direction only.
