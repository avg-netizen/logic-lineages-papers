Manuscript: [arithmetic proof](../../../17-permitted-control-canonical-comparison/sections/arithmetic.tex), lines 67–92 (exact field comparison), 197–220 (row high normalization) and 256–265 (linear greatest argument). This is an actual **weighted residual row family**, not an already-linear row or one-output forward circuit gate.

- Source row has exactly two ordered ordinary field occurrences, constant zero, coefficients c and −c with c nonzero. Equality to zero, signed nonnegativity and signed positivity (either requested Boolean polarity) are supported. No unrelated offset, arbitrary third term, general modulus, or mixed count normalization is asserted.
- `…ValueProof.lean` reads both literal fields with the actual ordered rows/domain formulas, not assigned independent outputs. The exact signed value reduces to c(u−v), including negative c, and its order/equality is classified by the sign of that coefficient and the actual comparison result. Opposite original field/rank order is exact by reversing the two genuine occurrences and signed coefficient.
- `…PaidProof.lean` preserves each original `ClosedOrdinaryValueDomain` (including true proper shape and own source norm), and derives actual shared rank-read hits at the exact max of comparison tail and both coded source norms. This domain payment is not a caller's assumed original result.
- `…StrictProof.lean` provides one fixed literal prepared packet before the greater value is assigned. It retains the optional genuine inverse-comparison lower field and the real bare input from the stable sorted packet, both at the original lower rank. It proves prepared syntax, actual correlated slot reads, both original field hits, and a uniform iff for every truly ordered greater update. The strict order graph guard remains positive outside the requested Boolean polarity. Miss/invalid original outputs are not interpreted as a false test.
- `…EqualProof.lean` uses the checked exact original same-input descriptor under its paid same-rank bound, no lower table. Two original real field hits and source guards still exist under that same rank assignment.
- `…OrientationProof.lean` stitches both strict orientations and the same-rank case to one literal dispatcher tied to the original first and second fields, using the applicable actual payment and shared new greatest rank.
- `…StatementChecks.lean` names actual signed value, strict/equal/reversed/oriented cases and aggregate. The route uses checked #718 all-order field comparison and the independently checked stable sorted typed packet.

The theorem does not assume or certify arbitrary signed mixed-field residual normalization, comparison-tree generation, raw Primrec for a new compiler, or whole arithmetic decision.
