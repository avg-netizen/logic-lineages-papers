Draft source only, pending native gate.

The frozen selected recursive row receives [predIndex,priorPair,H,K,M].
It uses the already-defined original idsAt on [K,M], hence the actual
ascending range at M+1, and original ordinary unpair selectors on the
prior pair, then calls the exact previously checked selectedStep on
[H,K,IDs,priorTerms,priorArgs]. No new constructor approximation.
The base is the original initialLayer, numerically the unshifted
standard pair of the empty term scratch and [0] argument scratch.

The independent gate aliases calibrate the actual row on its literal
pair, the actual primitive recursive paired report at every depth, and
both actual selected unpair projection programs against the respective
lists of the original grammar. This numeric result is not an arbitrary
open graph transport. The separate design note describes fixed-depth
width and fixed-width depth proof routes, neither proved here.
