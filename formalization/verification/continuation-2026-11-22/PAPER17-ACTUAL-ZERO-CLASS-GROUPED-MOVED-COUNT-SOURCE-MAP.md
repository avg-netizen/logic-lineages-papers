# Actual grouped moved count column of one original zero class

Source: Paper 17, sections/arithmetic.tex:130–162 (actual signed prefix
cancellation, same-input merge and transfer to the smallest surviving
input), with the support/charge accounting use at :164–194. The ledger
consumes the source scopes already checked in the current actual count
origin/disposition and least-rank transfer contracts.

ExactGroupedMovedCount is a local grouping bridge on a genuine
DisposedOrigins witness for countOrigins of the original selected class.
It does not take an already grouped output or assume agreement of sums.
The only additional input matches the optional actual survivor to its
finite rank and literal prefix interval. With no survivor that input is
vacuous and the ledger can realize only ended contributions; the actual
moved count column and the sum are both zero. The finite-rank arguments
are dummy in this case, not evidence of a live count.

Each actual ended occurrence emits no count, each survivor emits the
anchor prefix with its original signed weight, and each higher
occurrence emits exactly that prefix minus the literal transfer interval H
at the same anchor rank. The newer target does not independently assume
or choose H, its first-entry index, or the original rank; these are
retained from the checked ordered disposition and original cohort. The
exact ranked Finsupp column groups signed contributions by literal key,
so repeated/colliding lowered intervals are added and zero weights
disappear from support. Equal original labels are not inferred from
equal lowered labels.
