# Exact finite sums of the actual selected dispositions

Paper 17 arithmetic.tex:130–162 gives the signed zero-replacement
and rank-transfer identity per original count occurrence; :164–194
uses actual finite original support for the charge. This packet
connects the two checked ordered-list sums to the original selected
key set, not to the set of replacement labels.

The input is the same actually read, normalized and annotated row,
and the actual ordered disposition ledger emitted by the code-level
cohort. The anchor's literal finite rank and interval are matched,
not invented. Per-key disposition is a lookup in the typed original
CountKey ledger (outside-set dummy is never used in either sum).
The exact ordered Forall₂ match fixes the original key, original
ranked-row signed coefficient, and actual disposition at each position.
Distinctness on original keys is supplied by actual normalization,
so an insertion induction reindexes precisely once for each selected
key. Colliding lowered keys are still added in the moved Finsupp, and
cancellation is retained; no uniqueness of lowered labels is assumed.

The two conclusions give (1) the exact moved read count column as
the Finset sum of its actual signed disposition terms, and (2) the
actually installed replaceRow constant shift as the Finset sum of
the same original signed coefficients times the corresponding shifts.
These are conclusions, never given as equations by the caller.
No full row reduction witness, minimum construction, charge theorem
application or numbered promotion is claimed.
