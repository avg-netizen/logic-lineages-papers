# Paper 16: actual option and scratch for the literal selected grammar

From a genuine selected recursive observation, its actual left projection
is the chosen term-list report. Given actual coordinates of the original
unshifted measurement, the chosen generator receives that same report's
[depth, heads, types, maximum numeral] and inserts the true some tag.
Genuine syntax-success and measurement graphs then produce the same
original factored cover option and physical scratch payload, at the
same seed and original settings.

The proof adapts the literal original factored callback constructor to the
new real selected recursive grammar, using original object composition,
pair inversion and branch constructor, not numeric evaluation. It assumes
the genuine selected observation, actual measurement report and accepted
syntax where stated. It does not assert that any seed belongs to its cover
or identify a previous opaque callback with the chosen recursive program.
