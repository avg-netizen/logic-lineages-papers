# Literal finite low strips for one original affine → fixed-head pair

Paper 17, `17-permitted-control-canonical-comparison/sections/arithmetic.tex`, lines 1–53 and 225–274.

The prepended guard is precisely the accepted original three-row prefix (#961). It uses the same complete natural valuation as the test and any older prior guard. The theorem sets the generic low-strip slicer's **outer** polarity to true; its test predicate requires the canonical passing guard prefix and applies the requested original polarity **only** to the ordered test suffix. As an exact equivalence, the forward proof appends actual snapshots through the shared valuation, and the backward proof splits their literal lists, extracts the positive original graph from the guard prefix, and passes only the test suffix to the original predicate. Invalid or genuine-miss rows are not negative successes.

The compiler takes the original raw head, affine expression, input/output names, and existing raw test rows, at a supplied rank and finite bound. It constructs the original guard bytes (including canonical target zero and computed ordinal norm), appends test rows in order, and uses the exact existing branch code over the range of the bound. On canonical heads the literal code is the encoding of the very same typed branches on guard rows ++ test rows. No correctness of arbitrary malformed guard inputs, graph/DAG traversal, automatic cutoff, greatest-rank high-stratum projection, whole decision, or induction is asserted. Arbitrary prior predicates and tests are semantic only; the result does not decide them.
