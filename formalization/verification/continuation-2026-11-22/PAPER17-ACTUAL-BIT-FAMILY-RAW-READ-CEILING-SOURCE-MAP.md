# Paper 17: exact executable original read ceiling over literal signed-bit families

Printed source: `arithmetic.tex`, the source norms and affordability
part of the finite common cutoff in `thm:arithmetic`.

- Compute the exact existing original read cost atom by atom. Bare
  coordinates and fixed iterates over a bare argument have no read
  threshold. Proper entry/count payloads use both original ordinal
  norm codes and the same floor of two. Existing code/notation norm
  correspondence proves exact calibration on literal input, not just
  a conservative guessed threshold.
- Fold the unchanged finite original weighted terms, rows, clauses, and
  family with max and zero, without dropping zero signed weights,
  cancelling terms, parsing Boolean bits, or choosing a coordinate
  support order. Each code layer is primitive recursive.
- If one true original valuation pays this maximum at every actual
  source name and a given original row's operands are all proper, then
  the original measured read state exists on that same valuation, with
  its exact original constant, full ordered weighted terms and genuine
  field reports. The code itself does not verify these premises.
- This is a read-cost component, not the overall high cutoff. No
  ordinal admission, comparison, modular/tail/sign bounds, high-route
  compilation, closed-block effectivity, or numbered promotion.
