# Independent pre-scope: actual F2 descent
Approved two supporting targets for proof development. All four frozen pins independently match.

PolynomialDescent is an iff on every actual polynomial in the actual source splitting field, with existence and uniqueness of an actual finite-support F2 polynomial and exact degree equality. RationalDescent is an iff on every actual rational function fixed by the actual coefficient Frobenius lift, with unique actual scalar-extension preimage over F2. Both include zero and all d. Neither restricts to a reconstruction image nor assumes a descent certificate.

The proposed proof must pay finite support when lifting coefficients, use the checked scalar fixed-field theorem, and obtain fixed canonical numerator/denominator via exact canonical normalization. Forming the descended quotient requires a genuinely nonzero descended denominator. Injectivity of the actual maps pays uniqueness; the converse needs actual map composition/Frobenius fixation, not a claim that all splitting-field scalars are fixed.

This is mathematical, possibly choice-based descent, not an executable construction. Frobenius compatibility of arbitrary tuple reconstructions, rational-state/profile bijection, unrestricted geometric support, transitions/output, all-word observer and effective conversion remain distinct. No numbered promotion or native acceptance yet. No compilation or source edits.
