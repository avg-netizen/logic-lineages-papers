# Basic-only source-exact target spelling

The nine frozen targets preserve THIN-SOURCE-MAP.md's full scope. Only the representation of literal rational indeterminate/constants changes: rationalX is algebraMap (Polynomial K) (RatFunc K) Polynomial.X; rationalC is algebraMap K (RatFunc K). These are actual field embeddings, not variables with assumed properties. Canonical numerator/denominator digit and C definitions are otherwise unchanged.

The heavier upstream RatFunc.X/C wrappers and intDegree are not imported. Rational decomposition uniqueness must now be reproved by clearing genuine canonical denominators and using polynomial degree parity; it is not supplied as an assumption. As before, this is supporting-only and no mixed transient/complete profile claim follows. The failed Thin edition remains byte-preserved and unaccepted.
