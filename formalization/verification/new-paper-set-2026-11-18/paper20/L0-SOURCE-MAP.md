# L0 supporting packet source map

Source cartier.tex (L) defines L0(f dz)=C(z f dz). `EvenSelectorIdentity` identifies this literal RatFunc operation with the genuine canonical even square-root digit. The target quantifies over arbitrary perfect characteristic-two fields, not merely F2, so its square-root convention is retained rather than treating coefficient square roots as identity.

`EvenSelectorLocalPowers` is the actual local calculation in `lem:binary-transient`, in integer-power form with h=X-C(z). For poles of even order 2j substitute k=-j; the output is sqrt(b)*h^(-j). For poles of odd order 2j+1 substitute k=-(j+1); the output is sqrt(z*b)*h^(-(j+1)). At simple order one the killed term is constant. For other integers these are valid polynomial/local-power strengthenings. In particular z=0 and b=0 remain included.

It does not yet prove properness, arbitrary-word support bounds, profile compatibility/bijection, output descent or all-continuation exactness.
