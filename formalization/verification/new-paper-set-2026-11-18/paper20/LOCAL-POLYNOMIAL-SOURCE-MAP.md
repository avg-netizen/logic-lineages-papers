# Exact inverse-pole and embedded-polynomial scope

The new target contains the two displayed inverse-power formulas from `lem:local` literally, including j=0 and all z,b in every perfect characteristic-two field. Its second clause gives actual C(E P)=E(Q) for the canonical odd square-root polynomial Q, and Q.coeff n=sqrt(P.coeff(2*n+1)) for every n. This pays the actual rational differential/polynomial bridge, not merely a property of an unrelated polynomial digit.

Scope issue explicitly submitted for independent review: the printed unbounded sum a_n z^n is naturally read as a power-series rule, whereas this target quantifies only finite polynomials. It neither defines nor proves a rational-to-power-series/Laurent expansion bridge. Unless the source is independently determined to intend finite sums only, this packet remains supporting-only and does not justify complete numbered lem:local promotion. Existing Basic9 targets/proofs remain immutable.
