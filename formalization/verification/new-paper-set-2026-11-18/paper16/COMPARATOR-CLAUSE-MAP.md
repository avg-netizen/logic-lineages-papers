# Concrete comparator and bridge clause map

Signature.entries is the actual finite ordered ranked table; uniqueNames is
a table well-formedness condition, not an ordering theorem. lookupRank computes
arity and table position, and classRank rejects a different supplied arity.
Application/native/ranked class ranks are 0/1/2+position. Valid traverses every
head/base/extra node. PaperTerm imposes actual Typed EmptyContext and Valid.

Weak.var: one identical typed free name. No outer bound root is admitted.
Weak.abs: same fresh typed name opens both original lambda bodies with actual
one-value simultaneous substitution; both endpoints typed at arrow σ τ.
Weak.funHead: concrete head equivalence and equal result type; Matching removes
one target occurrence per source occurrence, preserving duplicates.
Weak.put: actual same head/base with empty extras and original result annotation.
Weak.select: one At witness in base or extras; a typed arbitrary ArrowPrefix
(including [] and function-valued residual τ); the exact actual full apply of
q to ownerCopies; then Weak of the returned value. No unary iteration.
Weak.fabs: same fresh typed name opens target body and is appended to source
extras, leaving base/head fixed; source is retyped from σ→τ to τ.
Weak.copy: concrete strict precedence, Whole premises from output-retyped owner.
Weak.stat: concrete equivalence, Multiset on base only, same Whole premises.
Strict.intro: successful actual persistent mark and Weak returned target.

Multiset.replace uses two literal Split witnesses, nonempty removed source,
Matching retained occurrences and Coverage of new target occurrences.
Coverage.cons can reuse any At occurrence of the same removed source for each
new target; Coverage.nil allows all removed source occurrences to be discarded.
Whole.cons uses q.type only to choose the owner output annotation, while Weak's
actual typing rules ensure equal outer type. No result-validity or comparison
oracle is passed to these relations.

NameBridge uses old Term only as raw syntax with (Ty,Nat) names. The new named
typing is intrinsic in the typed name and does not use old named Typing.
Alpha is independently generated by actual fresh typed binder renaming,
structural congruence and equivalence closure. The fresh target name is absent
from all body names; this is a safe generating rule, not assumed characterization.
AlphaExact, the two roundtrips, and OpeningBridge must prove characterization
and connection to canonical terms. EncodeTypingExact and EncodeValidityExact
connect independent named typing/signature validity to the actual carrier.
All target bodies are frozen before proof; none is yet claimed checked.
