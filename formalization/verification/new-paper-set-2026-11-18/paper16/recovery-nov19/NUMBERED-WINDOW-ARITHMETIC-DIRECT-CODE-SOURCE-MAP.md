# Literal numeric certificates for original direct multiset descent

Supporting scope for ordinals.tex 70–98 and 142–153. The independent
original typed direct relation from #461 and original scalar
positive-path fibers from #460 remain unchanged. No stage/Acc/I/J
claim, no arithmetic-language proof or ID_1.

The actual source and target data are literal ordered finite Nat
lists using the already verified exact fields codec. In the actual
relation permutations account for multisets of class addresses
without changing the positional data codec. An inserted occurrence
records exactly target, chosen removed dominator and its own
supplied positive-path Nat certificate. A DirectMultisetWitness
retains all kept, removed and inserted lists literally, including
order, duplicate occurrences and the given certificate codes.
Its decoder checks the exact expected tags and component shape;
decoding a record alone does not certify any original positive
path or typedness.

The coded layer first requires actual successful decodings. It
uses the exact typed scalar admission for the literal list members
and separately invokes the accepted strict direct witness checker
on both actual endpoint lists. Thus neither an absent result nor
a bad shape is equivalent to a valid address/witness, and no
unknown partition, dominator or path is searched. Empty insertions,
nonempty actual removed lists, and repeated dominator use remain
the original supported cases. The independent target explicitly
binds actual original typed lists, actual encodeFields equalities
and the original direct relation. Both endpoint domains are
recorded for later independent positive operator work.
