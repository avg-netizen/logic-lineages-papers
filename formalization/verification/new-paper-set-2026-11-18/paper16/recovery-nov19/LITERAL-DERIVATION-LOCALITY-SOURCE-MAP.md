# Literal finite derivation certificates and symbolic window locality

Source-first proposal, no proof or native result. This is a supporting
part of Paper16 `lem:window-locality`, not its later numerical-intermediate
assertion. `LITERAL-DERIVATION-LOCALITY-FROZEN.json` pins the two new files,
the actual symbolic grammar and judgment imports, and the two original TeX
sections. No frozen, old analyzed proof is changed.

**Exact original certificate:** `LiteralDerivationTree.Judgment` has
six sorts only: Weak, Strict, Matching, Multiset, Coverage, Whole.
The data `Tree` has exactly the constructors of those six original
`Spine.Comparison` predicates. It keeps original typed endpoints,
fresh-name equalities, head precedence/equivalence, actual occurrence
index and declared arrow-prefix type, literal whole special call,
splits/removals, and the actual unchanged-owner Whole argument
retyping. No constructor from the later marked-target extended relation
or ordered-list sort is added. The exact `CertificateExact` comparator
has both directions at every six-sort judgment, with no well-windowed or
ordinary side premise. Completeness produces an actual finite data
certificate, and soundness reads that same original rule structure.
Data trees distinguish distinct constructor trees even when their root
proposition has proof irrelevance. No witness extraction beyond Nonempty
from a proposition is needed by the exact calibration.

**Every actual certificate:** `rootTypes` uses original
`auxiliarySupport` and `auxiliaryArgs`, retaining every declared
base/result type, and adds Whole's original head declaration rather
than inventing an output or phantom term for that non-term judgment.
`footprint` retains the exact root and *all* recursive original child
footprints. For Select, its ctor-local support additionally includes the
actual selected term, all subtypes of the required original arrow-prefix
type (hence every supplied domain and successive suffix), and the *whole
real* `Spine.ownerCopies` tuple even if a tuple element is unused in
the literal result. The result itself is the actual continuation root.
Split/Remove/At index variables and q/r data are in the exact original
constructors; no alternate matching/copied source is substituted.

**Exact symbolic window**: `SymbolicLocality` ranges over every given
actual proof tree, every fixed signature and every subtype-closed finite
K. It requires only its original root type-admissibility. It then covers
all types of every actual symbolic term in that same tree; it is not the
existence of a replacement admissible proof of the same endpoint, nor a
decision-side restriction to an ordinary fixed observed pair, source-head
inventory or finite free ports. The two term-root sorts are precisely
the printed original symbolic locality, strengthened to the four actual
list-premise forms for induction. This does not pay future numerical
simulation paths, finite quotienting or the arithmetic ID1 proof.

Likely proof order after scope and target-only preflight: calibrate actual
six-sort data exactness both ways; support projections for literal removal/
partition/lookup; extract root type and fixed-window support of actual
selected argument and original arrow subtypes; keep original base/extras
and build exact whole owner list; use original simultaneous bound
substitution and actual typed call result; cover each printed constructor
with the same subtype-closed K. The numeric part of numbered Locality,
and positive simulation over the full raw/equivalence relation, remain
separate.
