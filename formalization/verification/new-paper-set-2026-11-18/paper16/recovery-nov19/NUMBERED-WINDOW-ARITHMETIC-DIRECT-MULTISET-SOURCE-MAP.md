# Actual direct multiset replacement for the J relation

Supporting scope for ordinals.tex 84–98, 142–153 and 155–181.
This is the original ordinary strict multiset replacement used
by J, on the admitted canonical class addresses of original
R_S from #460. It is not the narrower primitive mark-only
replacement used by the raw Stat rule (#453).

The independent semantic relation retains literal equal class
addresses as identical occurrences, uses both actual occurrence
permutations, removes a nonempty list, and assigns each
inserted value some removed dominator with an actual positive
original quotient path. The accepted ClassAddress and original
class fibers ensure that equality means actual same context,
result type and original primary class. Source and target lists
have actual typed admitted elements. The ambient universe
contains all represented finite contexts and all literal types;
lists may contain differing fibers (in particular, differently
typed base arguments), but every R_S comparison preserves its
own exact finite context and result type. No arbitrary function
context is encoded.

The checker is separate. A proposed witness supplies kept and
removed occurrences, and for each proposed inserted occurrence
names the actual removed value and its genuine numeric positive
path certificate. Both permutations preserve multiplicity and
ignore order as appropriate for multisets. Empty insertion
(deletion) is permitted, and several inserted occurrences may
use one removed dominator. The checker does not search for an
unknown partition or paths. The independent semantic relation
does not mention the checker. Full supplied-witness soundness
and existential completeness take the actual independent typed
relation as target. Permutation invariance and genuine typed
target preservation from a typed source are explicit.

This does not establish numeric coding of the multiset witness,
internal arithmetic formula representation, positive I/J stages,
well-foundedness of R_S or the internal ID_1 proof.
