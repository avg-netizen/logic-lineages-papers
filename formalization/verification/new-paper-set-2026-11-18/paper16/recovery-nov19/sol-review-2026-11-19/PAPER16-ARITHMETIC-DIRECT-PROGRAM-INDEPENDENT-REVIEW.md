# Paper 16 primitive-recursive direct-multiset certificate program

The programs support the witnessed multiset checker used at `ordinals.tex` 84–96. The primitive-recursive entry parser checks the exact tag and three-field length. The witness parser preserves the three lists, carries every inserted occurrence in order, and propagates rejection if any nested parse fails. The list test checks genuine permutation by equality of occurrence counts over the concatenated lists. A value outside both lists has count zero on both sides. This preserves duplicates in both endpoint partitions. The check also retains the removed-list nonemptiness test and uses the supplied positive relation in the order dominator, certificate, target. The final numeric checker accepts source, certificate and destination in that order and returns the original Boolean as zero or one.
