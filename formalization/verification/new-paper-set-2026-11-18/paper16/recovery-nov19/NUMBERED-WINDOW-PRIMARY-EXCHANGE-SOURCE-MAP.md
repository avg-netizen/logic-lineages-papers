# Actual one-contextual-primary-exchange: source map (support only)

Source: foundations.tex 3–28, 36–53, 57–90; ordinals.tex 13–28,
58–62 and 69–76. This packet isolates one literal original root
exchange occurring in one congruence context. It does not prove that
all Primary proofs are finite sequences of these exchanges, exact
full classes/canonical representatives, arithmetic, or ID1.

- **Root exchange.** Both heads must pass original declaration-retaining
  HeadInWindow in the same fixed signature and K, and satisfy original
  Spine.Equivalent (not mere syntactic identity, and never a pair of
  unadmitted .none ranks). The ordinary case requires actual result
  type equality and permutation of the original literal base list.
  The numbered root case retains current type, natural label and the
  exact ordered extra list; the permutation is only of its literal base
  list. The subsequent WindowExchange guard checks both genuine original
  Typed base judgments, with original head argument declarations.
  The actual original root rule does not require irreflexivity: a
  reflexive head exchange/permutation at a real root site is allowed.
- **One contextual site.** Only one of the body, a base/extra occurrence,
  or one of the two auxApp positions is changed. Surrounding annotations,
  unvisited siblings, head identity outside that site and extras order
  remain literal. The other application position is required literally
  unchanged. Both auxApp positions are allowed here because this is
  **primary equivalence**, not new RawStep closure. RawStep remains
  function-side-only for auxiliary application; no raw relation is edited.
- **No semantic bit definition.** ExchangeShape and ArgsExchangeShape
  are independent inductive skeletons matching these literal constructors,
  with actual guarded heads and actual List.Perm. WindowExchange adds
  `InWindow S K C τ` for both actual endpoints using one unchanged C, τ
  and K. The executable bits are separate, using packet444 literal term
  equality (including types/labels) for unchanged positions and actual
  decidable literal base permutation. Term/args shape reflection do not
  assert that arbitrary untyped raw shapes count as admitted exchanges.
- **Same exact finite context.** Window reflection uses the same original
  admitted/typed judgment. Its C-parametric wrapper models only a given
  bound-lookup parameter, not effective arbitrary-function coding.
  The concrete finite variant uses the nearest-binder-first list and
  exact original BoundContext.prefix Γ EmptyContext. Free names are
  still global typed pairs and unused ambient binder entries never widen K.
- **Soundness into original Primary.** Typed soundness must recover the
  original typed root witnesses and reconstruct the existing typed
  Primary/OrderedPrimary congruence in its exact C and type, preserving
  literal base and ordered extra semantics. Public symmetry and current
  annotation preservation are exact on the same structural shapes;
  neither changes the RawStep relation or turns an empty path into
  a one-site exchange. Original syntax, typing, Primary and accepted
  packet sources are fully unchanged.
