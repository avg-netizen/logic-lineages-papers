# Ordered numeric codes of both actual path certificate lists

Supporting only for ordinals.tex 10–76, especially finite raw and
equivalence witnesses discussed at 70–76. This proves literal data
decoding, not acceptance of a raw or original quotient path from
numeric codes, object-level arithmetic, or ID_1.

The already accepted #455 certificate records and #456 actual
single raw-witness codec are used unchanged. A raw hop is one
literal next NTerm plus one actual RawWitness, and the external
endpoint data remain external. A class-edge witness retains both
original possible raw representatives and the genuine single-witness
data. A class hop additionally retains the supplied destination
Nat class code literally; the codec does not compute, normalize,
trust or reinterpret it. Distinct tags/field lengths and partial
component decoders reject malformed nodes.

Both path list codecs map their actual ordered members through these
node codecs and use the accepted literal ordered field-list codec.
They preserve order, duplicates, and every intermediate destination
code and edge witness. Empty lists can be valid literal data, not
necessarily sound judgments: the already accepted actual raw path
checker tests its admission and equality in the empty case, while
the actual positive quotient checker rejects an empty certificate.
The path-list codecs do not change or define either path relation.
Each exact comparator covers literal successful decoding, roundtrip
and malformed rejection in the actual encoder image.
