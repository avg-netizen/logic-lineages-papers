# Cut occurrence transports: exact scope before proof

Source thm:cut occurrence transport paragraph. Four full conditional endpoints: weak matching composition; weak matching then strict multiset; strict multiset then weak matching; strict multiset composition. All use actual existing ExtendedMatchingTree/ExtendedMultisetTree, preserving Remove/Split/At witness semantics and the actual nonempty removed source list. Final target occurrences are each Ordinary via literal OrdinaryArgs. The actual whole right witness has treeSize < n; only CutEdgeTargets.Below S n is allowed as conditional induction input, not relational composition at unrestricted size.

First extract a requested matched source occurrence from a right matching: preserve the exact matching of remaining occurrences and a right weak edge with a count bound derived from the original right witness. Remove interchange must retain individual multiplicities. Matching composition then uses actual left Remove and right extraction, with bounded Below only at final ordinary target occurrences.

For partitions, align the intermediate Split partitions by actual occurrence identities. Retain only originally kept occurrences whose intermediate images are kept again. Removed source set is the first removed set plus source preimages of second-stage removed kept occurrences; nonempty is inherited from the first strict source, or from the nonempty second removed set under the first weak bijection. Final added targets have actual strict suppliers obtained by tracing their two-edge paths. Every right edge supplier is a literal subtree of the actual right matching/coverage witness with explicitly propagated count bound below n. Use checked bounded strict edge transports, not an unbounded callback. Coverage may have no targets; removed entries may have no selected supplier. In particular deletion without insertion must be handled, and no surjectivity of the strict supplier map is assumed.

Frozen endpoints permit arbitrary left witness sizes. Auxiliary partition combinatorics will be concrete data/witness manipulation, not an oracle or replacement of the actual multiset relation. These four conditional endpoints do not prove full ordinary-final cut until the final primary IH is supplied.
