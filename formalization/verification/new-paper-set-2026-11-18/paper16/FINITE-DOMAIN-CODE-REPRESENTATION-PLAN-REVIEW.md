# Independent representation design review

Approved for first supporting exact freezes, not source finite-lattice acceptance. The proposal faithfully refines the approved hereditary-domain plan: distinct actual context/observation keys, every nonempty arrow prefix, finite bounded coordinates with exact lower-domain indices, and executable monotone/natural retention.

Canonical key order must be deterministic from actual syntax equality, with completeness and uniqueness, including duplicate K/observation inputs and empty observation families. Table inputs range over full dependent tuples of retained lower values at the same context; output bounds are actual retained lower cardinalities. Off-schema defaults must not identify or add semantic values. Prove empty raw coordinate family behavior and nonemptiness of retained lower domains before indexing defaults or bottom/top.

Type-size recursion is acceptable only if lookup of D_rho^Delta is independent of the requesting parent and any implementation recursion bound. Establish descriptor coherence/transport explicitly, not by an assumed equality of unrelated callback results. The semantic encoding/decoding contract must quantify all manuscript natural monotone tables, not merely values already in the encoded range.

Restriction reuses identical context/tuple keys and applies actual lower restriction to inputs and outputs in (N); mere deletion of table keys is insufficient unless the reindexing proof shows this equality. Preserve arbitrary-extension identity/composition. Pointwise joins/meets and their empty-family cases should follow the genuine lower lattice and restriction laws. No extra availability or observation coherence is to be imposed.

First supporting packet may cover exact deduplication, all-prefix enumeration/proper-subtype bounds, and bounded vector enumeration. It cannot itself promote hereditary completeness, naturality or the source lemma. Review builder/retention/restriction contracts before their implementation. Marked-family (C), operator and adequacy remain separate.
