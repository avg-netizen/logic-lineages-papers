## Five exact contracts

- ConcreteFallback: actual all-input existing unpack/next Program3
  with named sparse option scratch encoding.
- OriginalLiveTick: comparison at any raw q/w/r including malformed
  codes; both true callback calibration hypotheses visible. The prior
  flag can be either Bool; the actual live machine ignores it.
- OriginalEncodedTick: full one-tick equality at every original state
  using the explicit scratch encoding. The absent case preserves state
  and the present case decodes all three actual carried inputs.
- OpenTerminalTick: true object-calculus graph on the identical input
  and output scratch with zero frame, at an arbitrary open flag term,
  by actual sparse ordered selector and original zero branch;
  root/fallback cannot be needed.
- OpenLiftedTick: true object-calculus graph of that same chosen unary
  tick at actual live scratch containing literal lifted source/witness/
  destination. Use actual raw optional successor and ordered fields to
  get the exact Program3 tape. Use chosen tag5 first branch and genuine
  frame graph #684; produce scratch [0,actual child frame].
