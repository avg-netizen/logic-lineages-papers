# Success-independent recursive requests

The complete source target will not restrict to successful derivation trees. Local request edges must have no Weak/Strict/Matching/Multiset/Coverage/Whole premise, either original or port-indexed. They retain only local syntax/type/precedence/occurrence/partition tests that enable an attempted recursive call.

Add an explicit full-call request sort beside the six comparison sorts. A Select parent generates this request from a selected occurrence and actual typed arrow prefix, regardless of whether original full application succeeds. Its state records the selected original term, the entire original-owner tuple, domain/result types and pending comparison target. Thus protected-variable full calls that fail are still represented. A separate edge from this request to the result comparison requires the actual successful full-call equality, because no result term exists when application fails. This does not erase the failed operation request or infer staged-call success.

For each rule with several comparison premises, independently generate an edge to each pending premise without requiring any sibling or the child itself to succeed. Matching preserves all Remove choices; multiset preserves all Split choices and actual nonempty removed set (including empty insertion); coverage includes each selected occurrence; Whole includes both source-owner comparison and tail; Stat includes multiset and Whole independently. Abs/FAbs use the canonical available port and literal opening/append; no successful child comparison assumption. Local failed guards do not recursively generate a term that does not exist.

The invariant covers the extra full-call state with the actual source and tuple universes, observed pending target, WellFormed slots and explicit requested domain/result types in K. All call type/domain/suffix obligations are internally derived from real selected occurrence typing, auxiliary source support and subtype closure. A reachable call may have apply=none. No classical success test or comparison relation premise is in generation.

Initial original Weak/Strict equivalence with canonical-port comparisons is a separate conjunction paid by normalization/erasure. Every-request invariant is a separate success-independent reachability induction. Exact frozen constructors will expose this separation for review before proofs.
