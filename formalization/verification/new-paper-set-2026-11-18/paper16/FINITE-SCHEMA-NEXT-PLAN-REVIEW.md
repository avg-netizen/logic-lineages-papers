# Independent conceptual review: finite schema supporting stage

Approved for exact supporting freeze. The restricted LowerCarrier sigma callback makes the proper-size lookup obligation explicit and is suitable for schema helpers, not a final semantic domain oracle. Proof irrelevance handles alternate size witnesses, but does not itself show different parent callbacks denote the same lower domain; actual canonical instantiation and parent-independence remain later mandatory proofs.

Actual context, availability, weak/strict Expr and full prefix/whole input tuple keys are appropriate. Use structural extensional equality and dedup, and prove no missing/extra key for each context extension, actual observation and full tuple. Numeric tuple coordinates must be linked to precise lower-carrier list indices, with bound equal to that list's length; do not silently identify duplicate lower codes unless later canonical lists are proved distinct.

Executable slot-extension filtering must be equivalent to actual Extends, retaining old occupied slots and admitting extra used slots. Reflexivity/transitivity are necessary. Schema may have zero output bounds for an arbitrary supporting callback; do not assert semantic bottom or nonempty carriers until actual retained lower domains pay nonemptiness.

Freeze schema construction and characterization separately. The later builder must prove exact hereditary interpretation, canonical carrier identity, retention/naturality, actual restriction and semantic encode/decode completeness. No source finite-lattice promotion from a generic callback schema alone.
