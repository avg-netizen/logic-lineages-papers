# Executable initial-pass predicate

After complete PureCertificate verification, the remaining executable front end must compute the exact already proved initialPeelingPass, not substitute a decision oracle or merely a semantically decidable proposition.

Proposed program: compute the finite list of original CNF exponent codes by a course-of-values table on the existing raw ONote code. Zero gives []; each nonzero node repeats its actual decoded head-exponent code by coefficient and appends the previously computed tail list. This is structurally the literal originalGapUnits list, including coefficient multiplicity. All raw inputs remain total; correctness is on normal codes.

The initial leading exponent code is the head code, and rawProfileCode computes the two original leading costs. The exact Boolean pass is:

* equal leading costs; or
* every exponent code after the first is less than2; or
* adjacent costs, exactly one remaining exponent2 and every other remaining exponent1, with the two literal original-list shapes distinguished: leading E>=3 with one subsequent2, or leading2 with one subsequent2. Require odd min(costs)+N(omega^E) in either case.

The norm of one leading monomial is exactly1+N(E). Proof must show the literal unit-list shapes are equivalent to the source existential ordinal shapes, using checked actual original-unit reconstruction and uniqueness, not an unproved parser invariant. In particular E=1 and single-unit gaps have no sensitive units; generated units never enter this list.

Targets should include all-code primitive recursiveness and normal positive-limit-gap equivalence with the exact initialPeelingPass. This remains a supporting front end. The subsequent full equal-gap certificate program selects reversed leading-cost sign when it fails, otherwise calls pureCertificateCode on actual log(delta). Its explicit tail must cover both initialPeelingRadius and pureCertificateRadius; actual initial divergence or return and original clocks must be composed in the full comparator proof.
