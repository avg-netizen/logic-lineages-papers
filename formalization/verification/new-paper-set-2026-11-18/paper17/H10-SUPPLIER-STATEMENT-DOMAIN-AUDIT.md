# Independent H10 supplier statement and domain audit

## Result
The inspected actual supplier is a closed undecidability theorem for exactly finite fixed-coefficient linear systems over N[X], including zero polynomial unknowns. It is not a theorem about arbitrary products of polynomial unknowns, nor a conditional H10 oracle. This matches the polynomial-system source stated at the beginning of current hardness.tex. It is a legitimate candidate for the later selected-source reduction, subject to fresh full recursive evidence and final proof-chain review. This audit is not acceptance of that future reduction or a complete line-by-line review of every Diophantine dependency.

## Exact interfaces inspected
`FunctionalHardnessCompletion.UndecidabilityDefinitions`: SystemCode is Nat × List (List (Int × Nat × Option Nat)). A monomial is an integer coefficient times a fixed power of X, optionally times one unknown. There is no unknown multiplication. WellFormedCode checks every original unknown reference against the shared dimension. encodedPolynomialSolvable requires actual decode success, well-formedness, and PolynomialSatisfiable(systemOfCode c). Although systemOfCode uses filterMap, the well-formedness guard prevents invalid references from being silently dropped in the language. Empty systems and zero polynomials are allowed.

`SystemUndecidabilityProof.polynomialSystemUndecidable` proves `¬ ComputablePred encodedPolynomialSolvable` with no premise. It pulls a hypothetical decider back through `H10Export.bridge`, which supplies a total computable Nat→Nat map and an all-input iff. The exported theorem bodies reference actual proofs, not assumed fields.

The input predicate is the separate `DiophantineCompletion.encodedPolynomialSolvable`: natural code decoding to a raw list, then actual integer-polynomial circuit syntax; original well-formed references; zero-allowing natural roots via HasNonnegativeRoot. Its undecidability proof reduces actual ordinary-code halting at zero, using Mathlib's halting theorem, not a caller-supplied undecidability assumption.

## Actual bridges inspected
H10BridgeProof handles both outer decode failure and invalid original polynomial input by the impossible zero-unknown system 1=0. Original references are validated BEFORE shift/circuit allocation. For a valid input it invokes the actual nonnegative-to-positive domain shift, compiled polynomial circuit, and literal full circuit linear-system encoding. The resulting validity is proved before using the raw output codec. H10AdapterProgramsProof provides the actual total primitive-recursive reduction, not merely a typed semantic map.

CircuitLinearDefinitions contains only fixed-coefficient linear rows. Multiplication gates are simulated through three square/triangular gadgets, not encoded as forbidden products of unknowns. ConstantRows constrains the scalar block to constants while leaving polynomial witnesses unrestricted. Input slack rows implement positivity without losing original zero-valued roots. CircuitFullSemanticProof obtains both directions from literal rows forward/backward and actual allocation/well-formedness; FullCircuitEncoding has only actual circuit well-formedness as a premise. It does not assume circuit satisfiability preservation.

At the Diophantine end, OrdinaryCodeProof covers all eight unchanged Nat.Partrec.Code constructors, including primitive recursion and minimization. Their closure hypotheses are discharged by structural induction; no RecursionFree restriction remains in the final graph theorem. The inspected closure targets preserve defined earlier computations in minimization and actual variable-length recursion traces. ReductionProof obtains one fixed polynomial representation of a fixed RE predicate and uses a proved computable specialization map. Choosing that fixed representation once is sufficient for a computable many-one reduction; it does not pretend to compute a polynomial from an arbitrary extensional proof.

## Remaining obligations before selected hardness acceptance
Fresh recursive evidence must include H10Adapter/validity/programs, complete literal circuit gadgets/allocation, full ordinary-code Diophantine recursion/minimization, polynomial representation/specialization, and the actual halting root. Standard axioms alone would not substitute for these semantic/domain checks. This statement audit found no missing external premise in the inspected theorem interfaces, but does not certify every lower-level proof line.

The selected lane must still prove the exact effective finite-query map from these well-formed codes, including masks/projection, original admissible substitutions, every query's source syntax/type bounds, and any malformed-input branch needed by its total decider contradiction. Semantic finite-family complements alone do not supply that numeric reduction. No level-three single-query or unchanged-G claim follows automatically.
