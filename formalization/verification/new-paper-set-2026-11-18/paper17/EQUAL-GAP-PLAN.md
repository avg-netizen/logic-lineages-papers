# Equal-gap complete certificate: proposed next scope

Source: entries.tex, proposition `prop:equal-gap`, entire proof through the following cocycle subsection. The just accepted thick-block theorem supplies only one internal phase separation. It does not yet give this proposition.

## Complete intended endpoint

A literal finite-code algorithm takes normal codes of two zero-or-limit prefixes mu, nu, and a common positive limit gap delta, plus the selected-control threshold B. It returns (T, sign). The function is computable on all raw codes, with an explicit harmless output for invalid domains. For every valid input and either actual selected control with that B, every t>=T has genuine first entries from countInitial(mu+delta,t) and countInitial(nu+delta,t); their actual entry norms compare by exactly the returned sign. Sign equal means identity for every t on the tail, not merely infinitely many equalities. Less/greater are strict on the entire tail. T includes both endpoint affordability bounds and all phase/breakpoint bounds. No phase enumeration, eventual-order, survival, residue, or threshold supplier is a premise.

The full frozen contract should include executable-code correctness and effectivity together, not just a semantic existential eventual sign. Threshold comparison tables and output offsets remain a subsequent full packet.

## Literal decision calculation

1. Read the actual ordinary CNF gap, its leading exponent E, and actual prefix costs s_mu,s_nu.
2. Count original sensitive units (exponent>=2), subtracting exactly one leading unit. If the leading profile difference is nonzero, all nonempty sensitive phases separate except a single quadratic unit with adjacent shifts and odd min-shift+retained-prefix norm. Represent this exception from the actual CNF, equivalently the two printed shapes. Zero sensitive units and equal leading shifts continue to step3. No generated unit is mistaken for an original one.
3. Form the finite joint partition from the actual two prefix CNFs. Choose the highest nonzero profile piece on [2,E), preserving right-closed endpoints and the top clipped piece. For a successor top bound use its predecessor only when in the piece; for a limit top use lower-edge+1. Empty pieces are discarded. Return the sign of s_nu-s_mu on the chosen piece.
4. If none, and E>=2, compare ceil(s_nu(1)/2) with ceil(s_mu(1)/2). For E=1 return equality. This agrees with the source's sign for first interval entry minus second interval entry.

## Required new proof layers

A. Finite profile bridge: raw finite CNF traversal computes exactly the existing actual relativeProfile, including ordinary absorption and coefficient weights. Joint partition covers every exponent in [2,E); selected representative has the sign of the highest nonzero piece. All exponent/breakpoint norms and generated successor bounds are proved from actual input tree weights. This is supporting only.

B. Actual initial-phase bridge: arbitrary finite tails are ignored only after proving actual limit-part invariance at the same clock. Peel actual original units and process generated lower blocks before returning; derive the single-quadratic exception and alternating parity for consecutive original quadratic units. A sensitive successor>=3 must derive a common thick block or earlier divergence using current actual budgets. No enumerator oracle.

C. Actual lower-phase bridge: prove strictly decreasing phase exponents, bounded-candidate no-skip, entry from beta+1 into a maximal profile piece, and common thick multiplicity>R+2 or earlier divergence. For a top limit-clipped piece derive the actual winning exponents and use saturation. No fixed phase assumed visited.

D. Terminal comparison: no nonzero piece gives synchronized phases through the pure quadratic step; derive the displayed coefficients and exact stopping order/equality. Propagation converts first divergence to the eventual entry comparison. Genuine first-entry existence and same norm orbit convert equal stopping events to equal outputs.

E. Effective bound: collect explicit finite source affordability data in the algorithm, bound dynamic prefix costs from actual norm, and use selected growth; prove numeric T sufficient. A guessed common tail is not accepted until this proof is paid.
