# Actual target-visit-or-earlier-divergence bridge (supporting)

Source entries.tex thick-block proof: lower remainder may separate already;
otherwise shared top visits must be established before applying moving residues.
This supporting theorem derives such visits on the actual common event clock.
It does not assert full lem:thick or supply an arithmetic separation oracle.

Inputs are same literal selected f and initial norm t, actual offsets mu/nu,
common positive limit sigma and positive target limit rho≤sigma, all below eps0.
Starts are literal countInitial(mu+sigma,t), countInitial(nu+sigma,t). Both absolute
initial/target norm affordability bounds are explicit; actual block/CNF identities
must later discharge them from the source R/M/tail. rho=sigma is admitted and
produces the already-at-top event0, supporting a reset without a hidden properness
restriction. Source offset domains limit-or-zero are retained.

Output produces both genuine FirstEntry indices and exact norm orbits. Through
each hit, actual relative limit stays ≥rho and equals rho precisely at that first
hit. Unequal hit indices give actual relative-limit divergence at the shared clock
min(i,j), with both still ≥rho. Equal indices give both exact countInitial resets
at input f^[i](t), preserving f and the common clock. No visits, count equality,
survival, profile constancy or relative recursion are supplied as hypotheses.

For full thick wrapper, sigma=rho_block+lower limit suffix (<omega^a) admits
arbitrary unprocessed lower remainder; this bridge either separates before block
entry or resets to the actual top. Apply again to next retained top rho1.
Full block source R/M/tail affordability, moving residues and within-block
separation remain separate obligations. No numbered promotion for this helper.
