# Independent conceptual review: executable initial pass

Approved direction before concrete freeze. Compared plan with actual
InitialPeelingDefinitions: originalGapUnits is descending CNF exponent list with
coefficient multiplicity, and initialPeelingUnits drops exactly the first unit
then reverses. Order can be ignored for the all-small predicate, but the actual
list calibration must retain order and multiplicity. Never add generated units.

Require all-input PR of a concrete total list/program and exact equivalence on
normal positive-limit gaps; that domain excludes exponent-zero terminal units.
Normality alone without the positive-limit condition would not justify the
proposed remaining-units-all-one description. All code-zero/malformed cases
still need total computational behavior, but no extraneous semantic assertion.

The adjacent-cost exceptional branch must match exactly one of the two literal
ordinal shapes. A count-of-2 test alone is insufficient if another original
exponent >=3 remains after the first. The proposed restriction that every other
remaining exponent is1 avoids this issue. Leading E>=3 and E=2 branches must be
explicitly distinguished and linked to actual CNF reconstruction/uniqueness.
Parity is min(c,d)+N(omega^E) odd, not just min(c,d) odd; the raw norm bridge
1+N(E) must be proved. Preserve E1 and empty remaining-unit lists.

Course-of-values recursion must use actual strictly smaller tail code and real
head/coefficient decoding; no caller-supplied CNF list or semantic decidability
oracle. Code profile/leading exponent calibration must share original raw codes.

Supporting only until the global executable certificate additionally pays the
combined explicit tail, initial first-entry/divergence clocks and pure-phase
composition. No targets/proofs/compiler were changed by this review.
