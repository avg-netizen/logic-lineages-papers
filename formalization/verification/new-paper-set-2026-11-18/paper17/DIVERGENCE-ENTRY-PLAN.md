# Actual divergence to final entry order

Next supporting dependency for the equal-gap certificate: turn an already proved oriented relative-limit divergence into strict final actual entry-norm order. This is not a supplied comparison oracle and not another conditional budget helper.

## Proposed exact scope

For a selected f/B, offsets mu,nu below epsilon zero and zero-or-limit, initial A,A' below epsilon zero, and an actual common event i, assume:

* the two actual states at i have the same actual norm t;
* both offset norms are at most t;
* the lower relative limit at i is positive and strictly below the upper relative limit.

Derive genuine original-clock first hits tau,sigma with i<tau<sigma, their actual entry norms equal to the corresponding iterates of f from t after subtracting i, and strict order of these actual entry norms. Include the reversed orientation through application with swapped states, not an unproved sign convention.

No assumption that the states survive until a supplied time, no first-hit supplier, and no per-step budget assumption.

## Proof bridge

1. Positive relative limit gives actual relative state at least omega. For each current state, reconstruct absolute limit as offset plus its relative limit. Derive a positive absolute limit and strict target-below-limit, not ordinal norm monotonicity.
2. Normalize each actual current state as countInitial of its actual limit and norm. The limit norm bound follows genuine finite-tail norm decomposition; source offset affordability is already the explicit actual t bound.
3. Use checked entry existence to obtain actual current first hits and norm orbits. Apply CountLag with k=0 and S=max(Nmu,Nnu), paying every strict budget inequality by S<=t<=f^[j]t and f(n)>=2n+4. Positivity ensures t>=2 via nonfinite-state norm, and each normalization satisfies the exact CountLag source domain.
4. Derive strict remaining-time order, then strict actual norm order by the selected control's strictly increasing iterate orbit.
5. Compose the original event clock. Since both current states are above their target+omega, ordinal trajectory antitonicity proves no earlier hit before i. Apply firstEntry_shift; no extra no-skip supplier.
