# Evaluation of the literal ordinal-coordinate syntax

This packet supplies tuple evaluation for current paper19 prop:counter-bound
and the restricted comparison co-r.e. upper bound in thm:control-hardness.
For every permitted literal control, an actual finite ordinal expression
with natural variable values evaluates to the encoded normal notation for
its canonical denotation at that control. This includes omega and all
three actual binary constructors. At a collapse node, the actual argument
is constructed by encoded natural multiplication and addition, after
which the generic first-finite evaluator computes the count-inclusive
scalar. The output is the actual finite ordinal notation of that scalar.

Effective evaluation composes the literal recursive syntax fold and the
bounded-code ordinal operations with the generic terminating ordinal
evaluator. It uses the source control's computability. The mathematical
calibration also holds without that computability premise. Policy source
assignment, compile-to-query calibration, and enumeration of arbitrary
countertuples are separate proof stages.
