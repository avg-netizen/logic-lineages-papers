# PolicyProgramSize: real copied-source compiler counts (supporting)

Current19 compiler.tex thm:compiler construction and literal-source retention motivate this packet. All four targets quantify over every actual typed BooleanCompiler.Program, including zero literals, empty contexts, and any supplied actual ground/unary source DAG.

CopiedLoad bounds literal occurrence-paid q.load by q.codeSize*(q.sourceMax+1). LowerCounts bounds the real lowered Plan vertices/equations/witnesses by 1000*q.load. ForestLoadCounts then bounds the actual compiled forest Result.nodes (sum of BOTH full source table lengths in every equation), number of real equations and context length. ForestCodeCounts composes the same actual output measures with the code/table budget, with context retaining its original Gamma.length contribution.

Proof obligations: actual source renaming preserves table size; actual unary call adds two table nodes and its fresh equation variable adds one; logarithmic literal construction includes zero; actual primitive gate forest has the checked vertex/witness counts. Original names and context extension are not replaced with fresh unrelated inputs. Use current checked PolicyMatrix, PolicyBinary and PolicyPlan syntax suppliers or fresh count proofs; do not inherit default-policy semantic status.

These are representation-local numerical bounds, independent of policy/control semantics. q.codeSize is the literal Program budget, not the raw serialized bit length. This packet does NOT pay final aggregate/strict/weak wrapper table sizes, encoded total reconstruction, source-language normalization composition, shared-input/reference bit-length complexity, or the full compiler theorem. Those remain separate. No parked period claim.
