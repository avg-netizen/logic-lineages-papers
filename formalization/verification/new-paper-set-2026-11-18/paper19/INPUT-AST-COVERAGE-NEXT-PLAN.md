# Literal AST coverage after interleaved normalization

InputNormalization is not the full input grammar. Next define a literal natural expression syntax on a typed external ground context: variable, binary Nat literal, addition, actual supplied closed unary Input applied to an expression, and actual supplied ground-output Input with its original external free-name map. Define a Boolean formula syntax with true/false, equality/weak/strict order of expressions, negation/conjunction/disjunction, and a sentence's finite existential ground prefix. The prefix is explicit; a separate prenex theorem would be needed if the accepted surface syntax permits existentials nested under negation. No universal quantifier is smuggled in by calling that existential arithmetic.

The natural expression compiler is a structural continuation algorithm carrying a typed renaming from the old context to its current context. Every produced natural node adds exactly one ground slot and lifts every outstanding actual source Input by ScopedDAG.renameInput. Variables can return their typed port directly. Unary expression arguments are first compiled to one shared natural slot if required; the actual closed source is then applied to that slot, not evaluated by the compiler. Each resulting value uses the common observation convention, rawScalar-1.

The Boolean expression compiler similarly carries a backward map for existing Boolean references and passes an actual root to its continuation. Literal truth/false use comparison of zero with zero (equality/strict order), so both have an actual root even for an otherwise empty sentence. A formula tree may duplicate expression occurrences; its bound is an AST occurrence bound only. Inputs already supplied as interleaved DAGs use the separately proved direct normalizer and are not expanded to trees. A real shared-source finite input encoding must distinguish those cases; do not advertise the AST bound for a shared DAG.

Exact immediate obligations: actual AST constructor completeness against printed grammar; explicit compiler to Input with typed map composition; same-valuation correctness at every returned natural/Boolean reference; binary literal and source-table occurrence bounds. Later valid-code serialization and joint computability require genuine indexed source codec/renaming reconstruction, not only a noncomputable mathematical existence result. Final whole source-to-source compiler still requires generic Program lowering/actual forest strict+weak observation wrappers, all original source free-name agreement, final literal shared DAG bound, and an independently checked full conjunction.
