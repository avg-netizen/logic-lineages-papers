The comparator covers every pair of actual ground-output shared source DAGs
in one ground-name context. It constructs the exact two observation leaves
and the manuscript's existential counterexample. For a weak query the
Boolean test compares the second observation strictly below the first.
For a strict query it compares the second observation weakly below the
first. The second source graph is shifted by the actual typed renaming
under the first output name. Positivity of canonical scalars calibrates the
two raw-minus-one observations at the original valuation.

The effective maps invoke the actual total compiler once and select the
corresponding strict or weak output. Typed code calibration and all-ground
output contexts are explicit. The selected output tables each have a bound
linear in the maximum supplied table length with a fixed constant. The
source costs are the actual interleaved costs of two observations, one
Boolean comparator and the terminal root. Shared graph identity and
polynomial actual DAG size refer to the same outputs.
