# Actual machine stage one: four supporting contracts

Supports the fixed H setup of current19 control-sensitivity.tex; does not prove the complete numbered hardness theorem.

The first three contracts copy the actual semantic enumeration/clock/halting propositions into a fresh current namespace. `program` decodes literal transition tables with work alphabet Fin(width p), width p=p.1+3, and binary inputs. This is NOT a two-symbol work alphabet. Surjectivity is on every actual table, including the documented malformed-code default convention. H is the fixed primitive-recursive Bool function `simulate e (t+1) []`; its truth must match an actual Run of <=t transitions ending in step=none, including zero transitions. Halts is independently actual TM0 eval domain, not defined as existence of an H witness.

The fourth contract fixes actual gamma b to `control b boundedH` by literal equality and supplies all eight permitted-control clauses for this same concrete simulator: Primrec, prefix, additive error, adjacent sandwich, double exponential growth, additive margin, F6 bound and real ratio limit. No new assumption of Primrec H is passed to the target; it is a conclusion of the first contract and must be proved.

Potential suppliers are the real finite-alphabet evaluation proof and existing generic fullPerturbedControl, with fresh native closure and axiom evidence. Stage-two universality must translate into this same enumeration or prove an exact effective bridge. Undecidability, Pi01 completeness, typed-source compilation and parity nonperiodicity are not accepted by these four supporting contracts.
