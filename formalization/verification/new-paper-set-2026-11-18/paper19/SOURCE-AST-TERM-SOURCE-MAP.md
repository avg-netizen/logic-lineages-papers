# Literal arithmetic AST embedding: three supporting contracts
Current19 def:source-language permits variables, binary natural constants, addition, actual supplied closed unary functions on arbitrary natural expression arguments, and actual supplied ground source observations with shared ground free names. SourceAST.Term has exactly these constructors and retains actual Input tables, arbitrary source internals and typed contexts. Term.eval uses actual same-p/f source rawScalar-minus-one; callValue uses input raw n+1 via the actual one-ground-variable application. No source evaluator is substituted by a numeric oracle.

Term.emit is a literal structural CPS algorithm to the accepted interleaved Input syntax. Its continuation receives a typed embedding of the previous context and a real returned Port. Addition compiles both arguments once; actual source leaves are renamed by ScopedDAG.renameInput, never separately valued. Unary arguments are put in one shared fresh slot via addition with zero, then the actual source is applied to that slot. The two-node overhead is explicit (cost4). This algorithm does not choose a realizing program by semantic existence.

Semantic is a standard supporting CPS preservation theorem with an explicit continuation specification; this premise is not counted as the whole-language compiler or assumed for a final result. The later formula compiler must instantiate it with a real syntactic continuation and prove the specification. Cost and SourceTables are uniform actual emitted Input budgets with explicit callback bounds; these are AST occurrence budgets, not bounds for expanding a shared DAG. The separate direct shared-DAG normalization route remains the one preserving supplied sharing.

Unpaid: Boolean formula AST embedding including true/false root, explicit existential prefix semantics and full grammar comparison, encoded valid-code reconstruction/computability/bit complexity, generic Program-to-forest lowering, actual strict/weak wrappers and full source-DAG output theorem. Three supporting endpoints only, no numbered promotion or hardness claim.
