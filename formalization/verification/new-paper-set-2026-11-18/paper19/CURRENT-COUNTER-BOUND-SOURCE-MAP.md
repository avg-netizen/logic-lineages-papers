# prop:counter-bound

`CurrentCounterBoundTargets.Full` represents both modes of universal comparison by the existing joint query encoder over one all-ground free context and arbitrary result types. The selected policy is the actual assignment policy, with its effective parsing premise for the numerical evaluator. The complete ordinal vector uses zero padding and the scalar coordinate uses the selected weak or strict relation. Tuples are encoded by predecessors of their positive raw coordinates. The bound is measured in raw coordinates, so a tuple entry x consumes x+1. For an empty context the only tuple is empty, already present at radius zero. The numerical extension treats malformed source queries as vacuously true, matching the independently defined quantified semantics. The finite-box search uses the actual source query and the actual evaluator.
