# Independent conceptual design review
Approved to develop concrete input definitions and exact coverage contracts, not to claim coverage already paid. The interleaved acyclic actual arithmetic/source and Boolean DAG is preferable to assuming A-normal input.

Keep original existential inputs and produced natural wires distinguishable; every reference must be a typed previous reference. Two-pass extraction may compute a final natural-wire renaming and transport each recorded Boolean atom there, avoiding repeated ad hoc index lifting. Prove commuting reference maps under append and actual capture-avoiding source-table renaming. Boolean results must not feed arithmetic unless a new explicit source-language primitive is separately justified. Internal source types, binders and primes must not be restricted by the all-ground external wire context.

Critical semantic convention: define whether each natural wire denotes raw positive scalar or its rawScalar-minus-one observation; use one exact convention throughout literal constants, addition, unary source application, generic source Input and boolean comparisons. No extra plus-one/seed can be hidden at interfaces. Generic source semantics must remain the same arbitrary permitted p/f, not selected17 control semantics.

Provide literal printed-language AST embedding and genuine shared input-DAG normalization, both actual algorithms with reconstruction and same-valuation correctness. Preserve earlier source node sharing rather than duplicating terms under repeated Boolean references. State binary literal/reference sizes and source-table multiplicities explicitly in quantitative bounds; a tree bound is not a shared-DAG bound. Raw malformed decoding behavior, valid-code reconstruction and actual joint computation are separate obligations. Arbitrary interleaving with later existentials must respect original scoping when prenexed.

PolicyPlan Boolean-matrix semantics is a useful smaller supporting packet, explicitly not full input coverage. GlobalFlatten cannot supply missing arithmetic/source normalization. Full source grammar comparison, exact typed shared forest and eventual weak/strict wrapper remain mandatory before full compiler promotion.
