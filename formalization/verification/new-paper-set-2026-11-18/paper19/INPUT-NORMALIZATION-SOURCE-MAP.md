# Interleaved input normalization: four supporting contracts

Source: current19 sections/compiler.tex, existential arithmetic with supplied source observations and Boolean DAG sharing, and the proof's arithmetic/source flattening before its Boolean matrix.

This packet does NOT claim all-E_src coverage or thm:compiler. It supplies an actual non-A-normal, typed interleaved DAG syntax and an explicit normalizer to the existing Program. Boolean nodes may appear before, between and after natural producers. Natural producers bind one real ground variable referenced by later nodes; Boolean references are Fin to earlier nodes. There is no predicate, scalar-assignment, or normalization oracle. Supplied observations are actual typed source DAG Inputs on the current context; closed unary sources are literally applied to a typed earlier ground variable. Source internals remain unrestricted for the general compiler.

Wire convention is explicit on both sides: naturals are observation values rawScalar(p,f,inputs rho,t)-1, while source raw coordinates are rho+1 inside the actual existing scalar semantics. The normalizer never evaluates sources. It preserves each arithmetic/source node once and carries a renamed deferred Boolean DAG across natural binders. The terminal BooleanWire table has two natural reference slots per Boolean node, including dummy zero slots for logical nodes; it copies REFERENCES, not arithmetic or source producers. ReferenceNaturality and WireCorrect quantify every wire. Normalization quantifies every p/f and shared valuation, with no growth premise because this is structural semantics only.

Budgets refer to actual Program.codeSize/load/sourceMax. Input.cost charges one per add/observation, log2(k)+2 per literal, three per unary, three per Boolean node and one terminal root. Initial deferred m nodes cost 3m. Actual supplied source table lengths are bounded using their maximum and multiplicity; no free table sharing is assumed. The target is exact codeSize, exact sourceMax and a real load upper bound.

Unpaid after this supporting packet: literal full source AST embedding into the interleaved syntax, quantifier-prefix coverage, encoded valid-input reconstruction/Computable normalizer and bit complexity, Boolean matrix/Program to source forest correctness under p/f, actual strict/weak K/I wrapper, final shared-source-DAG bound and restricted hardness constructor preservation. In particular, defining this explicit input language alone does not prove the source coverage theorem. No numbered credit.
