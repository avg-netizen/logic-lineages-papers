Arithmetic conditionals are not an E_src primitive; if desired they require a separate encoded extension, not assumed here.

A literal source-language AST with var/constant/add/unary/actual observation and Boolean relations/connectives provides a second explicit coverage witness: structurally compile it into this shared input DAG, preserving a supplied DAG directly when already shared. State separately the AST semantic embedding and the source-DAG semantic normalization; do not claim a tree-bound for a shared input DAG.
