Context/type compatibility is proved from concrete guards, not supplied as an oracle.
- RejectionAndCounts states rejection iff concrete guard false, literal unconditional raw constructor sizes, and successful output validity/context/root/type/count. - Effective is genuine joint Computable of concrete checked Option routines on all raw inputs. Computing code is numeric/list construction plus the actual computable codec validator; typed existence is a proof conclusion, not implementation via choice.

Application newest-first table is app :: argument-table ++ function-table, with function root shifted by argument length. Eraser is app :: lambda :: second-table ++ inserted-first-table; app argument is second-root+1 and lambda body root is second-length+first-root. Both checked guards reject invalid code, mismatched contexts and incompatible result types. Eraser requires both ground. No semantic term equality replaces graph identity.
