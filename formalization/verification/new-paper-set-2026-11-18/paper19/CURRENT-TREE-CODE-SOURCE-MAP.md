# Shared source input for numerical observers

The typed DAG bytes used by the arithmetic compiler also suffice for obtaining the actual original source tree code used by the canonical vector evaluator. The algorithm folds the existing reverse-indexed DAG table and selects the original root. Exact calibration compares against the original source decoder's `Input.term`. This bridge pays effective access to the actual assignment of a supplied source. Its output may be larger than the shared DAG.
