# Genuine arbitrary-computable-policy macro bridge

The existing Policy selects a finite ordered binary Shape(n+1) from macro
site and arity. Literal association can affect later size/partial clauses,
so a default-policy theorem cannot be transported merely by ordinal value
equality. Introduce actual postorder shape code: false leaf, true join.

A total stack interpreter consumes the given operand codes left-to-right,
pushing each unchanged. A join pops right then left and pushes literal
node4(left,right). Underflow/missing input/bad final stack return none;
there is no normalization or reassociation. Prove exact framed execution on
a real Shape, including preservation of unused operand suffix and initial
stack, hence exact typedCode(expand shape operands). Prove the total raw
interpreter genuinely primitive recursive on script/input data.

Give seven macro sites stable numeric tags with encode/decode calibration.
For an arbitrary fixed actual Policy p, Effective p means its actual finite
shapeCode(p.shape(decodeSite tag)n) is a Computable numeric function. This
is exactly the source's computable selector assumption, not a successful
assignment/decision oracle. A joint macro interpreter composed with this
program must be Computable in site/arity/operand list, and literal source
repetition (including explicit zero totalization) must be calibrated too.
No uniform evaluator of arbitrary machine indices is asserted.

This supporting packet does not yet thread the program through full
partial/box/abstraction/source assignment. Those later recursive compilers

then reuse the existing all-policy structural and original-domain proofs.
