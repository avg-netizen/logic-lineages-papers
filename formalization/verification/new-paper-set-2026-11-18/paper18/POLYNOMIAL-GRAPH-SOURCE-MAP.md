# Complete current18 polynomial graph translation

Current m:thm:graphs asserts effective word-linear graphs for all fixed nonzero
polynomial limits, common finite degree, exact domains/finite exceptions,
and total functional existential translation for arbitrary fixed nesting and
addition. Proposed PolynomialGraphTargets expands all head and expression
obligations before aggregating them, rather than importing an old full target.
Candidate is PolynomialGraphCompletion.FullStatementChecks.full_polynomial_collapse_graphs.

## Literal heads and all-natural graph domain
ValidHead requires canonical decoded ordinal, actual nonzero limit and
lambda<omega^omega. PolynomialHeadCoverage ranges over every such actual
ordinal, not a selected finite notation subset. headValue is actualCollapse
(lambda+n) under literal Phi. headCalls compiles the actual principal word
with prefix masses; headRow shifts n by actual norm(lambda), then compiles
all calls into integer-linear sums of unary words. Source alphabet is signed
shift,Phi,V,X,E with degree restrictions. LetterDomain/WordDomain follow each
actual intermediate value, not an assumed total extension of a partial word.

The concrete implementation proves the stronger all-natural-input domain,
so graphCutoff=0 and graphExceptions=[] are correct only as part of the
proved HeadGraphExact/TotalFunctional clauses. They are not a shortcut omitting
small inputs: HeadSourceProof derives CallsGenuine for norm(lambda)+n from the
actual principal peak word, then WordSemanticProof proves exact compilation
including counters. This implies 2*headValue equals the emitted row at EVERY
natural n. Thus a singleton tail clause with empty exception table satisfies
the printed finite disjunction formulation. No function is applied to an
integer-linear sum: prepend composes unary words only. HeadPrograms supplies
actual primitive-recursive compilation, degree and symbolic equation programs.

## Full source-expression bridge
Expr retains numeral, original named variable, binary addition, fixed natural
scale and fixed polynomial collapse nodes. ValidExpr checks every actual head;
nesting is unrestricted and natural scaling is repeated addition. Each literal
source occurrence gets one fresh node, while repeated original variable names
remain the same names. rows emits child equations and the parent arithmetic
or exact collapse equation. expressionPackage contains common degree, complete
allocated natural existential prefix and literal rows. existsNodes binds only
those fresh names. This is a real source-to-formula compiler, not a finite
oracle/domain certificate or a semantic graph postulated to exist.

The expanded target includes allocation/disjointness, free-name support,
all-word domain/degree checks, soundness, realization preserving original
names, uniqueness on every allocated node, exact correlated existential
semantics even when the result name is already an input, and total functional
graph for a fresh result name. Literal instruction calibration and primitive
recursive numeric package generation are required. ExpressionExistentialProof
translates the finite existential prefix to a frame-preserving valuation and
proves actual source denotation, not independent wire values.

## Scope boundary
This is a full graph construction theorem, NOT a decision procedure for these
existential graphs. Current new m:lem:graph-domains and m:cor:polynomial-booleans
are not promoted by it. Their composition/Boolean decision bridge requires
separate proof and may not assume free-parameter QE. No supplied head graph,
source correctness, computable compiler or domain oracle remains in the full
endpoint. Independent scope review, native recursive evidence and final
review precede any current numbered promotion.
