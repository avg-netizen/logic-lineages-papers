# Mixed runner block source map

Supporting source-elimination mechanisms from Snyatkov2008 pp49–50, cited for current m:thm:snyatkov. Not a complete numbered theorem or exhaustive branch classifier.

ReverseWitness and ReverseElimination are the actual minus-oriented coefficient-close branch, using signed shift e, arbitrary x-free anchor (possibly nonlinear), real Phi and full original Matrix. Source strict upper comparison is strengthened to the supplier's nonstrict comparison. Coefficients zero and one are not excluded. Literal low-end recovery is part of the conclusion, and original guards remain in every substituted branch.

LinearBounds and LinearElimination are the actual nonlinear/linear runner-up branch with both original nonlinear occurrences and domain guards. The explicit i != j restriction is retained. The j-occurrence below the leading occurrence is data in the guard; no claim is made that arbitrary formulas automatically satisfy it. Both plain-Phi and Phi-H constructor kinds are covered.

ActiveBounds and ActiveElimination pay the finite alternative when the would-be substituted name has its own active hyper occurrence. Identical names i=j remain allowed throughout this family, including the block endpoint. This avoids silently replacing a nested-H issue by an unsupported normalized-grammar closure assertion.

All three Block targets use actual iterated Function.update over arbitrary Nodup bound lists containing the eliminated name. Reduction includes exact truth equivalence, Nodup remaining names, length+1 equality/strict decrease and no newly free name outside the original guarded matrix. Other bound names need not be absent from anchors or from the full Matrix. Correlation is preserved by shared valuation, not separate occurrence witnesses.

LiteralCode includes both the actual erased binder list and matrix code. Programs requires real joint all-input Computable construction and the actual PR numerical bounds. There is no caller-supplied elimination, domain, termination, or growth oracle.

No general QE/common/balanced/Snyatkov promotion from this packet.
