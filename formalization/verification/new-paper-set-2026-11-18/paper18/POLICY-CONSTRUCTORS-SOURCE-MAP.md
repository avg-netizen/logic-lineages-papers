# Supporting arbitrary-policy literal source constructors

Motivation is current18's literal canonical forward interface. This packet
covers actual zero/successor/case/recursor constant clauses and complete
application/box construction for ANY source Policy, plus genuine joint
computability when its actual selector is Computable. Full assignment,
partials and abstraction are NOT claimed or numbered-promoted.

ConstantCalibration compares directly with AdmissibleAssignment.assignment
on literal constant terms, including actual recursor type/result level and
policy-selected numeral two. No recursor coordinate or internal type level
is truncated by an imposed bound. onesCode replicates source one fields;
recursorCode invokes the actual policy numeral program and installs omega
at inputLevel+2 as the source clause requires.

TailCalibration uses literal n=0 absent-tail clause (f+g), otherwise actual
policy numeral n followed by the ordered optionalBoxTail shape on precisely
[f,g,numeral]. No reassociation is substituted for that shape. Complete
ApplicationCalibration preserves source result truncation, all positive
box fields and scalar collapse with actual bound arg level, zero padding
outside original input vector lengths and policy-selected tail.

Programs requires real joint computation on all raw numeric/list inputs,
including the Option failure convention, composed with the actual fixed
policy selector. It does not assume compiled operands denote canonical
terms to prove effectivity. Exact typed calibration requires all actual
vectors, not caller success of a downstream compiler. Selector effectiveness
is the legitimate source hypothesis only; no assignment or comparison oracle.

Remaining work is substantial and explicit: arbitrary Computable-policy
partial recursion (the existing PR-only generic-recursion argument cannot
simply be reused), positive/scalar abstraction, then whole raw original
source assignment/calibration and source equality assembly. No broader
policy frontend or arbitrary source corollary follows from constructors alone.
