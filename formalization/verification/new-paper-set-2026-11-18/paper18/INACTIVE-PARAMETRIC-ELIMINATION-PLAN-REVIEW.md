Direction approved for concrete definitions and an exact supporting freeze, not acceptance of a solver or discharge of tag1. Read plan, actual NormalFormDefinitions and OrderedOccurrence live/inactive definitions. This targets a genuine missing branch: a computed quantifier-free transformer with all-valuation existential equivalence, support removal and one-binder block decrease. A fixed-valuation additive Boolean decision cannot substitute for it.

Required exact obligations:

1. No-live must be tied to the actual occurrence roster and binder i. Sum every linear i coefficient; discard zero nonlinear contributions only arithmetically. Existing materialized domain rows stay at their original Boolean positions, including under negation. Formula.eval itself does not automatically assert meaningfulness: the endpoint must transform the supplied Formula exactly, with guardedAtom preservation as a derived application, not silently add a global domain conjunction.
2. Preserve every other original name as one shared parameter valuation. Nonlinear parameter terms may be treated as symbolic row values only with a literal substitution-back theorem, not independently existential values. Cancelled linear coefficients, zero weights, repeated summands and absent occurrences must remain covered.
3. Freeze an executable finite candidate construction, not a chosen list assumed complete. Common multiples need an explicit positive default for empty coefficient/modulus lists. Signed coefficients and natural-domain x>=0, negated inequalities/divisibilities, no-bound cases, modulus one, and residue coverage all need internally proved completeness. A residue enumeration or semantic existence assertion alone is not elimination.
4. The result must inhabit the actual usable quantifier-free syntax with i absent. Candidate expressions involving division/floor cannot simply be inserted as new primitives. Explain coefficient normalization and finite residue branches so output closure is literal. Substituting parameter expressions must not create unsupported nested nonlinear arguments; inactivity should ensure any i-substitution affects only linear occurrences, and this must be proved.
5. Derive arbitrary Nodup-block equivalence for i in the block, exact erase length and support containment from the all-parameter theorem. Do not assume remaining binders independent of nonlinear parameter terms. Raw computation must be total on malformed inputs and calibrated on genuine encoded syntax; no semantic correctness claim for malformed data is needed.

Before proof, inspect existing candidate suppliers by definitions and theorem assumptions, not naming/status. The local repository contains several Presburger/linear normalization routes, but this review does not certify any as the required parameter-preserving supplier. Freeze the actual transformer and full semantic/closure/program endpoint; staged support is fine, but tag1 stays pending until that full endpoint passes independent final review.
