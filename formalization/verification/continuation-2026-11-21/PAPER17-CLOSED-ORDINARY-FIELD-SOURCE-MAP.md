# Paper 17: closed ordinary value and count fields

**Target-only successor to fixed-entry closed scan (722).** No new proof,
native evidence or numbered credit.

Source: arithmetic.tex (“The finite matrix language” and “Residues,
finite strips, and one-variable projection”), with actual entry/count
definitions for proper intervals. This packet evaluates fields at one
already fixed and unchanged natural coordinate; it does not substitute
through a matrix or quantify any additional coordinate.

- **Domain check:** checked 720 terminal guards in both orientations
  enforce normal endpoints and zero-or-limit shape for each. Strict raw
  ordinal comparison gives `μ < λ`, so λ cannot be zero; the norm test is
  exactly `N(λ) ≤ x` at that coordinate. The guard must be Primrec and
  calibrated on arbitrary decoded codes and actual NONote endpoints.
  Neither an extra high-tail cutoff nor affordability of unrelated
  endpoints is required.
- **Guarded proper entry:** validated inputs reuse the literal accepted
  722 fixed-entry scanner at `(λ,μ,x)`; wrong endpoint shape, malformed
  code, or insufficient input norm returns invalid, distinct from a
  genuine missed proper entry. The underlying all-t fixed scan remains
  unchanged; this source call guard never treats truncation in
  `countInitial` as affordability. The precise earliest index and
  entry norm, and absence of any actual first entry for a valid miss,
  are retained as separate result clauses.
- **Ordinary value:** use the original 714/716 tuple codec. A bare iterate
  applies the real finite iterate to x; the exponent-zero case is the raw
  coordinate, not a new nonlinear term of the matrix language. A proper
  entry applies exactly its outer exponent to the accepted hit norm.
  Preserve invalid and miss through nested options, with no numeric
  default. On a source proper affordable field, exact equality to the
  actual `FieldValue` relation and true absence are required.
- **Count:** project the exact hit index of that same entry without
  evaluating a fresh affine input or deriving it from the value.
  Preserve invalid and genuine miss and prove the actual `FirstEntry`
  graph. All three definite routines are required computable relative to
  a computable control, using 722 and actual finite iteration.
- **Excluded:** identity calls `λ=μ` are not proper; later use actual
  `EntryTableProof.identityEntry` with source affordance and zero/limit
  endpoint to obtain `E=x, count=0` separately. No general circuit
  domain, no shared strip substitution, no Presburger elimination, count
  cancellation, or promotion of the printed arithmetic theorem.
