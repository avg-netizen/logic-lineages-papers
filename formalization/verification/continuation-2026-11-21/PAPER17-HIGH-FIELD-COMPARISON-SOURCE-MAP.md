# Paper 17: high-input all-order actual field comparison

**Target-only supplier.** Existing 704, 712, 714, and 716 are unchanged.
No new proof, native evidence, or numbered credit.

Printed source: arithmetic.tex ordinary value fields and `lem:field-comparison`.
This staged supplier handles the all-large branches after the chosen uniform
explicit bound, before finite-strip substitution in the arithmetic proof.

- **Calibration to original syntax:** raw tuples use the existing 714/716
  conventions. Apply the exact 712 short command to both original fields,
  keeping its same outer exponent after reduction and keeping an unchanged
  long field at a negative test. The callee is the original field form
  applied to the normalized fields. No undeclared new comparison routine
  or semantically unconstrained encoder is substituted.
- **Effective common tail:** maximum of the two original short tails and
  the three normalized tails: same-input, distinct forward, distinct
  swapped. Both original coordinates must be at or above this *one* bound. The
  three wrappers, bound, and orientation answer transformation are
  required primitive recursive on raw natural tuples. This includes
  all tags/codes for termination of those numeric programs, not for
  semantic correctness on malformed codes.
- **Order and exact semantics:** `x<y` runs the actual distinct compiler;
  equality uses the actual same-input constant at the same shared
  coordinate. `y<x` swaps fields and inputs, retains the oriented exact
  form, and reverses the sorted comparison answer to recover the original
  orientation. A linear form specifies its actual encoded parameter H,
  the table sign (including equality) and properness; it uses an actual
  field value at the smaller coordinate and the inverse-table row in the
  greater coordinate. This is not independently variable data.
- **Actual values:** returned values are the original source fields,
  on both selected controls with proper fields and on-tail inputs.
  Preserve the same input in every mention of a field, and use the
  short-normalization equivalence to transport values in both directions.
  Explicit uniqueness quantifies any other proposed actual source values.
- **Future work excluded:** mixed low/high infinite strips, exact
  closed hit/miss flags at small coordinates, full arithmetic atom and
  quantifier-elimination calculus, concrete cancellation bridge, and any
  reclassification of existing numbered record 704.
