# Paper 17: short-field preprocessing supplier

**Status: new append-only target only; not proof, native evidence, or numbered credit.** Existing record 704 and all its frozen files are unchanged.

Source: `17-permitted-control-canonical-comparison/sections/arithmetic.tex`, ordinary-field syntax and `lem:field-comparison` common-iterate/endpoint peeling, plus the short interval convention immediately before count-core. The supplier makes the reduction for a source field already of short interval shape explicit.

- **Recognition.** `shortGapLength` runs actual raw notation subtraction on encoded normal endpoints. `rawShortGapLength` inspects the paired result: a nonzero constructor, exponent the literal code of one, zero remainder; the stored coefficient is one less than the returned positive length. `ShortGapRecognition` requires both directions for every positive length on proper NONote endpoints: exact literal canonical tree, actual gap `λ-μ=ω*k`, and original endpoint `λ=μ+ω*k`. Monomial equality in the reverse direction uses injectivity on normal notation; ordinal addition/subtraction uses proper endpoints, not algebra of commutative addition.
- **Effectiveness.** The raw parser, endpoint classifier, exponent/unchanged command and explicit bound are separately required to be primitive recursive on natural codes. The normalization bound is built from the actual raw norm algorithm and must calibrate on every NONote pair to `max Nλ (max (Nμ+3) (max 1 B))`. No norm oracle or opaque effective witness is assumed. Static proof suppliers are `ordinalSubCodeEffective` (OrdinalEndpointProgramsProof), `ordinal_sub_note_code` and `normal_norm_code` (ThresholdNoteCodeProof), `rawNormCodePrimitiveRecursive` (RawNormCode). Their reuse and the new compositions are obligations for the later checked proof, not credited here.
- **Normalization.** Iterates unchanged. Zero classifier leaves the proper entry unchanged and certifies LongField. Positive classifier returns exactly `iterate (a+k)`. For both selected controls and each proper field the normalized field is LongField and has exactly the same actual values for every input on the printed short identity tail, with the outer `f^a` preserved. Use actual `ShortEntryIterate` and uniqueness, not supplied extensional equivalence.
- **Exclusions.** No comparison decision or reversed/equal/strict order assembly, no effective comparator tail, no action on malformed codes beyond primitive-recursive totality, no row/circuit eliminator, no change to the printed or owner frozen endpoints.
