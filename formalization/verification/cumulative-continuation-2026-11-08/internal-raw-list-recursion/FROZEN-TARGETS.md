# Original raw-list recursion and map — frozen targets

Date: 8 November 2026. Frozen before proof authorship.

The six targets specify all-input evaluation calibration and actual internal
nil/cons graph laws for concrete Program ASTs. The programs use the unchanged
source successor-of-pair list codec, original head/tail programs, and a finite
course-of-values table built by the original primitive-recursion constructor.
All arbitrary parameters and symbolic head/tail/output codes are retained.

The generic recursor is a supplier for explicit original path checkers. Its map
specialization supplies the list traversal in the existing liftPath transformer.
The intended next source consumer transports positive path acceptance from an
internal one-edge preservation derivation. These targets do not assert that
unpaid edge preservation, full positive lifting, or paper06 lem:id1 is proved.
Evaluation calibration is separate from the internal graph proof. No inference
from standard-model truth to InternalCalculus.Derivation is used.

The internal constructor law has only the literal cons-graph guard. A tail
result is existentially bound inside the formula, with its actual recursor
graph and actual step-program graph. The map constructor law names actual head
and tail computation graphs and equates its output graph with the original
constructor graph.
