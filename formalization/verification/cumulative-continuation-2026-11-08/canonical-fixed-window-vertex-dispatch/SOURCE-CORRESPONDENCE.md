correspondence and source pins. Independent static review must precede native

## Source and exact selected programs

Paper 06, `06-godel-t-termination-ordering/paper.tex`, lines 537-556, fixes the
finite subtype-closed window, original well-typed numbered reduction,
function-side auxiliary application and least-code representatives. Lines
563-588 use arithmetic typed descendants and application in accessibility.
The present package exposes a fixed-window implementation of the original
numeric application vertex and a concrete arithmetic invariant. It does not
complete the application path rule or the accessibility argument.

The Data is exactly `InternalCanonicalDescentSelection.Data`, with its
original `oldValidity`, `member` and `oldEdge` finite Program leaves. No
correctness, typedness, fixedness, invariant or application-lift field is
added. The typed checker is literally
`InternalCanonicalDescentSelection.selectedTyped data`: membership of the
requested type, recursive source validity V(value), the original raw left
type tag, and T(value)=value. It has no old typed, H or N-fixed test.

The preceding checked `InternalCanonicalQuotientEdgeSelection` supplies the
SAME Edge and typed aliases. Edge uses its exact W, consisting of the original
guarded application-step checker and V(raw target). The source representative
is N if V accepts, zero otherwise; the target representative is N on every
input. No source/target default is changed here. The checked canonical Edge
typed-propagation theorem uses only typed(x,typ) and Edge(x,y,certificate),
for arbitrary symbolic typ, with no calibration or target-typed premise.

The dispatched five-vector order is always
`[context, domain, codomain, argument, value]`. At selection,
`window = OrdinaryArithmeticQuotient.contextCode symbols S table`.
This is the encoded symbols/S/table window, never the ambient context Gamma.
Gamma remains fixed in leaf and original vertex calibration.

The activation AST is exactly the conjunction of:

1. context = window;
2. canonicalTyped(value, 1 + Nat.pair domain codomain) = 1;
3. canonicalTyped(argument, domain) = 1.

Each conjunction tests equality to one. The active branch composes the frozen
`InternalCanonicalQuotientEdgeApplicationLift.actualJ` with projections
`[1,2,4,3]`. Thus the actual active value is
`C(domain,codomain,value,N(argument))`, with the argument normalized internally
and the function value passed unchanged. The inactive branch is literally
the complete original `oldVertex : Program 5`, with all five inputs unchanged.
It is not a new zero, source-filtered or fixed-window fallback.

The pre-existing `InternalFixedWindowVertexDispatch` is a structural example,
not the new semantic supplier. Its Data, typed checker and old C are different.
None of its frozen files is edited or silently identified with this package.

## Concrete invariant and later compatibility boundary

For fixed window, sigma and tau, the five-input invariant is the exact-one
conjunction of the following five arithmetic conditions:

- context = window;
- domain = typeNumber sigma;
- codomain = typeNumber tau;
- canonicalTyped(value, typeNumber (sigma arrow tau)) = 1;
- canonicalTyped(argument, typeNumber sigma) = 1.

Only value changes along an edge. The same canonical Edge typed propagation
transfers its function-typing conjunct from x to y. The context, domain,
codomain and argument are the unchanged path parameters, so their factors
are retained. Internal conjunction introduction reconstructs the exact
invariant graph at y. The path API's `edgeGraph (edgeChecker data)` and the
canonical selection's `edgeAccepted data` unfold to the same original graph3
AST, with the same one output and the same endpoint/certificate ordering.

This supplies only local invariant preservation, not EdgeCompatibility.
A later compatibility target must combine the frozen dispatch graph equality,
both endpoints' invariant/activation facts, the exact coordinate equalities,
and the application-lift packet's checked SAME-Edge rule, after that rule is
accepted. Its certificate transformer must still receive RAW argument, not
N(argument). No such compatibility, path checker preservation, or lifted
certificate conclusion is asserted by this packet.
