# The quantified large/maximal plain-Phi branch

The literal compiler preserves the source normal form's Boolean tree and maps
its original atoms through the proved large/maximal plain-Phi atomic compiler.
The explicit linear frame asserts a structural sum cutoff and that the chosen
raw name dominates every original name. The checked linear elimination algorithm
is then applied to that actual framed formula.

The requested existential equivalence includes the original frame and the
original formula evaluated at the quantified natural. It does not claim that
this single branch exhausts all witnesses. Domain formulas already at Boolean
positions are preserved as ordinary input syntax, not silently imposed globally.
General nonmaximal branches, hyperPhi coverage and global nonlinear QE remain
pending. No source-register label is promoted by this supporting component.
