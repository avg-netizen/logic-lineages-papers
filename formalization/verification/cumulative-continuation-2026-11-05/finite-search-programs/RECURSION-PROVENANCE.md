# Actual composition and conservative finite graphs

The frozen numerical functions first consult the actual scoped-Phi additive
decision and otherwise follow original Boolean/finite-bounded recursion. Their
calibration uses the literal source codec, not a renamed syntax or a replacement
valuation. Bounded child contexts use the already proved exact finite update.

The computation proofs reuse unchanged source-code-decreasing child graphs:
formulaChildren for admission and BoundedSourceProgramsGraph.children for the
answer. These may enumerate children that a recognized supplier node does not
need. Its assembler ignores those child values and uses the actual checked
supplier answer. Thus the conservative finite graph proves computation of the
exact frozen function; it does not assert a step-for-step execution trace or a
cost bound. Every child still has a smaller original formula code.

The supplier's scope test, decision, actual source term evaluator and finite
child enumeration all have checked total numeric programs. No oracle or
computability premise is passed by the caller. Current environment tables and
original binder shadowing are retained. Only the frozen restricted domain is
claimed, not unrestricted nonlinear decision or full BASE.
