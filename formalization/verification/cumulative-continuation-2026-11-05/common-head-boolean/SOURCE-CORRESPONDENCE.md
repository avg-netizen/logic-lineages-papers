# Boolean common-head source fragment

This supporting paper08 comparator extends individual comparison closures to
arbitrary finite Boolean combinations of equality/strict order of original
raw common-head operand codes under one fixed genuine head list. Translation
preserves original negation/conjunction/disjunction positions and uses one raw
valuation. There are no added independent values for common basis entries.

The source AST is explicitly defined as this restricted comparison fragment;
it is not a claim that arbitrary word terms or the whole printed grammar have
already been encoded. Source operands are interpreted by the unchanged existing
codedValue and compiled by the unchanged existing common-head compiler.

Six exact targets cover literal meaning, homogeneous named-prefix meaning,
literal postfix stack compilation, actual finite-ambient block answers,
existential/universal closures, and actual total computable numeric programs.
Repeated/unused/shadowed binder names are retained. Missing ambient entries are
zero. Semantic claims concern the actual Formula.encode programs; malformed
postfix inputs have concrete defaults but no semantic validity assertion.
No quantifier alternation, QE, full first-order BASE, or whole-source promotion.
