The literal source body admits arbitrary nested Phi terms and Boolean polarity,
but no internal source quantifier. The requested original named existential block
is followed by the actual fresh graph witness list. The exact joined-graph theorem
then identifies the original SourceFormula.existsNat fold at every ambient
valuation. Negation yields the original all-universal source block. Repetition,
shadowing and original indices are retained, without renaming assumptions.

The parameter frame fixes remaining original names to the supplied finite ambient
valuation. Six exact targets require semantics, literal witness/code calibration
and actual primitive recursion. This is uniform existential or uniform universal
block decision, not QE, alternating prefixes, malformed-code validation or BASE.
