# Multivariable plain-Phi dominant boundary

This component targets the remaining dominant-boundary step for original
NormalForm occurrence rows whose summands are variables and signed-shifted
Phi values. HyperPhi is explicitly excluded by the literal row test, even
when an occurrence has coefficient zero. It is not a general nonlinear BASE
eliminator or a treatment of the wider finite-degree word language.

The actual Phi input of every original occurrence is computed using one
shared valuation. Existing equal-input collection merges those exact values;
its zero-coefficient blocks are deleted only after summing all correlated
weights. The row's original occurrence mass and absolute shift budget give a
uniform natural threshold. No supplied tail sign, growth bound or independent
valuation of nonlinear values is an assumption.

At a maximal raw name, dominance requires an original Phi occurrence whose
whole actual coefficient block survives. A cancelled occurrence alone cannot
supply maximal-name provenance. For any greatest surviving block, the source
row's sign then equals that block coefficient's sign. Empty collections have
a separate exact linear-remainder theorem. Natural truncation below a signed
shift's domain is retained literally; the results do not move or discard the
original source domain guards.

The finite ordering/equality guards needed to select collected blocks are not
yet assembled here. HyperPhi leaders, arbitrary nonlinear anchors, exhaustive
source-case selection and the global induction remain pending. The numeric
claim is exactly primitive-recursive computation of the syntactic test and
structural threshold data, not a whole quantified decision program.
