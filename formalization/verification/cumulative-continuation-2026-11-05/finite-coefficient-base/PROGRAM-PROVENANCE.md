normal notation and raw source code types are the existing repository types.

actual finite arithmetic of one, natural addition and 2^a*b. Its value soundness
uses checked natural-ordinal finite arithmetic, not a size surrogate.

collapse identity for every k,n; naturalProduct_omega_finite identifies the original

translation and assignment no-Omega theorem. Its acceptance is proved, not assumed.

about deciding the positive vector coordinates or the whole source query is made.
