# Uniform decisions with fixed free parameters

The original row formula remains unchanged. Exact linear equalities fix every
original occurrence name outside the requested quantified block to its supplied
finite ambient valuation (absent entries are zero). Existential closure of this
framed formula is proved equivalent to the literal named existential prefix at
that valuation. Negation gives the corresponding all-universal block. Repeated
and shadowed binder names are allowed; no alpha-conversion assumption is added.

The actual checked frontier decides each frame. The numeric compiler calibrates
literal lists, coefficients and Boolean syntax and must itself be proved primitive
recursive. Unsupported hyperPhi syntax is rejected without cancelling zero weights.
This is uniform parameterized decision, not quantifier elimination, an alternating
prefix algorithm, malformed-code validation or the complete BASE theorem. Original
source-domain formulas in the input retain their Boolean positions.
