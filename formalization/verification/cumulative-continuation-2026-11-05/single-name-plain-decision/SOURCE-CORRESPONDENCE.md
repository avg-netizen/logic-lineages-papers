# Closed decision for one-name plain-Phi existential/universal sentences

The rejecting Option Bool algorithms first check the exact literal one-name
plain-Phi fragment, then apply its actual all-witness quantifier elimination and
evaluate the resulting formula at zero. Valuation independence is proved from
the original source occurrences: it is not assumed of the compiled output.

Both truth and falsity must match the original quantified natural semantics for
any ambient valuation. None means outside this fragment, never false. The
literal numeric algorithms must have exact code calibration and be primitive
recursive. This does not decide arbitrary parameterized formulas, hyperPhi
quantifiers, alternating prefixes or full nonlinear BASE.
