# Actual primitive-recursive finite-frontier existential decision

The numeric state contains a Bool and a finite list of original formula codes.
The actual finite splitting step is mapped over that list, and a primitive
iteration runs for the original occurrence-name length plus one. No function-
valued recursion, semantic evaluator oracle or unbounded search is used.

Exact state/iteration/decision calibration and a direct encoded decision contract
are required. The rejecting Option Bool procedure decides existential closure of
plain-Phi Boolean row matrices only. Alternating/parameterized/hyperPhi quantified
cases and full nonlinear BASE remain outside this component's claim.
