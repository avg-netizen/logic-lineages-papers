# Literal finite-search graph

Graph nodes are pairs of the finite zero-default valuation table and the original
source code. Atom nodes evaluate the actual source terms through the proved
zero-default evaluator. Negative and conjunctive nodes retain literal child
occurrences. A bounded existential node parses the original guard and enumerates
the actual range of its bound value, creating one updated-table/original-body
child for each candidate natural number. If guard parsing fails it has no children.

All child formula codes are strictly smaller than the original parent code.
This remains true when the actual bound value, number of children or length of
an updated table grows. The graph theorem is the unchanged narrow
BalancedBoxEvaluation.Graph.exactDecreasingGraph supplier. Finite mapping is
proved from its checked fold program, not assumed as a recursive oracle.

Assemblers use actual numerical atom tests, Boolean operations and finite any.
The graph computes the frozen raw algorithm on every natural source code.
Literal calibration and the genuine codec bijection connect this algorithm to
the original source semantics, including active outer values, shadowing and
zero defaults. The six-target comparator remains unchanged. General unbounded
nonlinear quantification and a primitive-recursive running-time bound are absent.
