# All-witness elimination for the one-name plain-Phi fragment

The literal fragment test excludes hyperPhi and requires every original raw-name
occurrence, including zero and cancelled coefficients, to be the quantified name.
Below the structural cutoff, the existing exact finite substitution compiler
enumerates every witness. At or above it, the quantified maximal-name branch
applies because every original name is that same quantified name.

Their disjunction therefore covers every natural existential witness in this
fragment. Negation supplies universal elimination with the original Boolean
semantics. The numeric algorithms must calibrate to the literal construction and
be primitive recursive. No semantic oracle or new premise about witnesses is
introduced. Parameter-dependent/nonmaximal names, hyperPhi, arbitrary quantifier
alternation and full nonlinear BASE decision remain pending.
