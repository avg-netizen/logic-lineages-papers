# Exhaustive finite splitting of plain-Phi existential satisfiability

Every original name is finitely substituted below the actual structural cutoff.
Otherwise a maximum of the actual finite name list supplies a large/maximal-name
branch. The finite disjunction of actual branch compilers must therefore cover
every satisfying valuation; no external exhaustive-branch premise is allowed.

The step first removes all currently linear names, computes the actual all-small
Bool answer and returns the literal maximal-name successor formulas. Every such
successor preserves plain syntax and strictly decreases the actual nonlinear-name
count. This prepares a bounded frontier iteration, but that complete decision
algorithm and its numeric effectivity remain separately unproved.
