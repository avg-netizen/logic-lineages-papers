# Genuine finite bounded source quantifiers

This restricted source fragment recognizes literal existential bodies beginning
with the original conjunct x < t. The actual bound term may contain arbitrary
nested Phi and outer quantified or free parameters, but must not contain the
newly bound name. The entire original body is evaluated during finite search.
No original binder, bound conjunct, Boolean position or shadowing is rewritten.

Atoms admit all actual BaseTerm syntax, including bound-dependent Phi. Every
quantifier must have the explicit independent finite bound. Negative source
formulas express finite bounded universals with the usual empty-bound behavior.
Six exact semantic targets cover literal recognition, invariant bound values,
finite search, actual source truth, finite ambient decision and the literal
bounded universal. No unbounded nonlinear decision or full BASE completion is
claimed. Numeric all-code calibration and effectivity are a separate stage.
