# Actual numeric source Boolean graph compiler

The payload computes the literal syntax test, joined nested term, and relative
Boolean predicate from radix-five source codes. The numeric name shifter turns
relative graph output names into their actual fresh indices. The existing graph
machine executes the joined term; its resulting rows are conjoined outside the
original Boolean predicate. The checked frontier answer then decides closure.

Seven exact targets require literal shift and source-code calibration, actual
primitive recursion of the numeric routines, and correctness for encoded source
formulas. Unsupported source quantifiers are rejected. This is not malformed-code
validation, parameterized QE or alternating-prefix decision.
