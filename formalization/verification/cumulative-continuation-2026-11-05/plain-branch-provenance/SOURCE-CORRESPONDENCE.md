# Plain-Phi branch closure and literal nonlinear provenance

This package targets the outstanding syntactic closure needed for recursive
multi-name elimination. Only membership of unchanged original summand values is
claimed, not preservation of multiplicity or order. Actual guard formulas contain
only linear summands. The maximal-name atom compiler and actual linear elimination
therefore cannot invent nonlinear summands; the selected name disappears.

The resulting finite set of nonlinear names must strictly decrease when the
selected name originally occurs nonlinearly. Plain syntax is preserved. These
are properties of the literal algorithms, not a supplied ranking function or
new semantic premise. They do not by themselves establish exhaustive multi-name
branch selection, recursive decision, alternating quantifiers or hyperPhi QE.
