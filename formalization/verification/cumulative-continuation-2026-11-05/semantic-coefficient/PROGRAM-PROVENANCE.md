# Exact numeric pipeline

The actual raw program first evaluates the original closed positive syntax using `Source.ForwardTranslation.encodedClosedPositive`. Its calibrated output is the normal notation code of the original coefficient's ordinal value. It then executes `encodedFiniteTest` and, on acceptance, `encodedFiniteValue` from the checked ordinal descent interface.

`encodedFiniteCorrect` supplies both directions of the finiteness test and the exact natural value of every accepted normal notation. `encodedClosedPositiveCorrect` supplies literal syntax-code calibration. Their primitive-recursive programs compose with a Boolean branch and Option constructor; there is no search or new termination premise. The output is positive on actual closed positive coefficients by the independent `closedPositiveValuePositive` theorem.

The old structural coefficient program is not edited. Its positive answers imply equal original ordinal value, which the complete semantic recognizer accepts at exactly the same natural number. No converse agreement of rejection sets is needed or claimed here. Scalar and vector consumers still call their existing structural compiler until a separately checked extension is constructed.
