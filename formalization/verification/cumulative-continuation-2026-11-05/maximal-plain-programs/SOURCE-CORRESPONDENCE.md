# Effective large/maximal plain-Phi atomic branch

Explicit total numeric functions mirror the original active-index guard,
inactive-mask compiler, actual Phi residue fold and structural cutoff. Exact
calibration is required on the unchanged row/atom data and radix-six formula
encoding. Primitive recursiveness concerns these literal algorithms, including
the already-defined actual common residue function, not a semantic oracle.

The corresponding typed semantics apply only under the explicit large/maximal
plain-Phi hypotheses. This component does not add nonmaximal branches, hyperPhi
coverage, contextual quantifier assembly or a global nonlinear decision theorem.
