# L2: internal source computability

The owned route is the internal counterpart of the already checked native
`SourceComputabilityArrowLeastProof.actualConditionalArrowLeast`,
`NumberedInverseApplicationAccessibilityProof.actualInverseApplicationAccessibility`,
`SourceNeutralExpansionProof.actualNeutralComputabilityExpansion`, and the
source lambda/substitution proofs. Native accessibility or standard-model
truth does not count as an object-language derivation.

The first packet uses the unchanged `InternalSliceInduction` scalar slice.
Its invariant at x says that every original typed/same-Gamma application
graph from f and the fixed argument to x has I(f). The invariant retains the
current inductive predicate and all free parameters. It requires only local
arithmetic domain/carrier/transport and application compatibility derivations.
The original program graphs, context parameter, even tag, negative invariant
occurrences and existential output graph are retained.

`DomainCarrier` and `DomainForward` are explicit unpaid source arithmetic
rules; they are not new fields in `SourcePresentation.Data`. The relative
inverse-application theorem does not claim to construct them. L1 is assembling
the concrete uniform source/computability pair and its certificate lift.
L2's logical bridge quantifies over that same eventual pair rather than
choosing a second incompatible existential package.

Further original neutral, multiset, constructor, lambda, substitution and
all-term derivations remain pending. No numbered source promotion follows
from this packet's specification or a successful target-only build.

The raw scalar packet selects the same source-validity/fixed-transition
factors already present in canonical typed acceptance. Its external target
is exactly `NumberedNumericCarrier.canonicalCarrierTest` on every raw value,
including malformed values and decoded nonuniverse terms. Data precedes every
window/Gamma. The separate symbolic typed-to-scalar proof works for arbitrary
Data and imports no calibration assumption into the internal judgment.
L1's final scalar wrapper must use global valid-window dispatch and preserve
the original fallback on malformed/nonclosed contexts; a fixed local K is not
a uniform source selection. The decoded-parameter extension needed by all-input
outer assembly is recorded separately from the frozen literal-parameter gate.
