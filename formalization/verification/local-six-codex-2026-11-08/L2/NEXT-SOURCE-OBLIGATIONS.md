# Concrete source obligations after inverse application

The relative inverse-application proof uses the original scalar-slice
leastness rule. Its arithmetic premises must be proved for L1's eventual
single normalized source/computability pair. That pair need not have the
same AST as an older existential selection.

1. `DomainCarrier`: the original typed function belongs to the scalar
   carrier at the same context/window. This needs an internal relation
   between the chosen typed and scalar checker ASTs. Equal external
   evaluations do not prove the symbolic implication.
2. `DomainForward`: source reduction preserves the original application
   domain. The concrete forward SAME-Gamma theorem supplies its guard
   component when L1 retains the literal GammaGuardedSource constructors;
   the existing typed-down rule supplies target typedness.
3. Internal bottom/spine computability at a symbolic shared Gamma. Literal
   raw bottom at type tau has packed code
   `Nat.pair (typeNumber tau) (Nat.pair 3 (typeNumber tau))`. The outer Object
   code must retain the runtime Gamma. A fixed-numeral Gamma result is not
   the uniform object-language proof. Membership and source validity of the
   bottom must be derived from actual selected arithmetic programs.
4. Internal neutral application decomposition, following the exact
   `NumberedNonLambdaApplicationTargets.ActualNonLambdaApplicationEdge` and
   `NumberedNonLambdaPathsTargets.ActualNonLambdaApplicationPath` contracts.
   An application of a nonlambda has only a bottom successor or a successor
   induced on its function. The original path certificate, universe filters,
   typed representative, and possible nonempty tail must remain explicit.
   Calibration of an opaque old step program is not this derivation.
5. Source C-to-I follows type induction using a concrete computable bottom
   argument and internal inverse application. Neutral saturation then uses
   the nonlambda decomposition and L1's downward-closure result. Constructor
   computability also requires the actual multiset J induction, followed by
   lambda/substitution and all-term assembly in the same combined body.

No arbitrary C-closure, accessibility premise, decidability oracle or
reflection rule is inserted to stand for these source obligations.
