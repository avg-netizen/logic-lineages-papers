## The independently payable maximum-row clause

## Concrete strict-decrease dispatcher to implement

For a nonempty duplicate-free bound list B, compute one literal cutoff T from
all row coefficient masses and all positive divisibility moduli. Generate a
finite disjunction of the following actual smaller-block problems; recursive
calls remove at least one original bound name.

1. At the first name in B, substitute each numeral below T into the WHOLE
   original formula, then remove that name. This covers assignments whose
   maximum is below T. It is harmless that it also admits other assignments:
   every branch is still an original concrete witness.
2. For every distinct pair i,j in B, identify i with j LITERALLY in each
   occurrence (including Phi arguments) and remove i. Do not use the free-term
   substitution that moves Phi(j) into constants: j remains bound.
3. For each i in B and each nonnegative source row with nonzero selected head,
   substitute the five free terms `boundary(i,row)-2+d`, d<5, in the WHOLE
   formula and remove i. A branch needs no maximum guard for soundness: any
   substituted formula supplies a concrete original witness.
4. For each i in B, impose the literal unique-maximum frame, x>=T and the
   outside-band guards for ALL nonnegative rows. Rewrite each atom using the
   actual sign/residue clauses. All selected-name occurrences are now linear.
   Apply the concrete tied-term Cooper adapter, then recurse on B without i.

Every original assignment is covered: a small maximum uses (1); a repeated
maximum uses (2); otherwise the maximum is unique and large, and either a row
band uses (3) or all bands are outside and (4) applies. Coefficient-zero rows
have no band and keep their exact remaining constraints. Completeness does
not require the same nonlinear summand to appear in every row.

## Concrete H-free expanded graph node plan

The existing inverse graph theorem removes a mathematical prerequisite. A
fresh typed graph compiler can use the following local source-node forms:

* A numeral/variable gets one ordinary linear output row, as already done by
  SourceTermGraph. Addition and literal multiplication get linear equations.
* Truncated subtraction gets `(a<=b AND z=0) OR (b<a AND a=b+z)`.
* Division by a positive literal c gets `c*z<=a<c*(z+1)`; division by zero
  gets z=0, matching the actual total expanded Term semantics.
* Phi gets the existing literal row `z-Phi(a)=0`, with shift zero.
* Phi inverse gets four fresh nodes u,v,w,z, with u=z+1, v=Phi(z),
  w=Phi(u), and `(z=0 OR v<=a) AND a<w`. Put z last to retain a simple
  last-node output index. Forward references in these equations are harmless
  only after actual local totality/uniqueness is proved from the checked floor
  inverse graph; they are not a supplied solution field.

For a full expanded Matrix, place ALL total functional term-graph equations
outside its arbitrary Boolean predicate. This includes terms under negation
and in unselected disjuncts. Compare only their fresh output names with
ordinary linear rows; modulus zero in Matrix must become output=0, while a
positive modulus uses the existing NormalForm divisibility atom. No H nodes
are needed for the proposed source compiler's output class.

The structural source-binder induction can then project the original binder
together with all these fresh graph names using the SAME uniform block
