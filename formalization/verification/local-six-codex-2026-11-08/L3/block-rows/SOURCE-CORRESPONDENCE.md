# Actual whole-block parameter-row closure

The original Snyatkov 2008 printed p51 eliminates an entire quantified block. Its inverse-selected dominant-boundary terms depend only on free parameters, not the remaining bound names. The existing NormalForm.Row has an Int-only constant. It cannot represent such a replacement as a retained symbolic constant without an actual bridge.

This packet keeps the original summand occurrences and adds two literal expanded terms for the signed constant. The value is their difference plus the original signed occurrence sum, at ONE original valuation. No new parameter name/value is existentially quantified. Whole-block independence tests only these constant terms; original bound summands remain in the occurrence list.

A concrete structural substitution moves each occurrence of the replaced original name into those constant terms and retains exactly the literal source filter of other occurrences. Order, shifts, coefficients, multiplicity and zero-weight occurrences are not normalized away. Replaced zero-weight terms are retained syntactically. Original constant terms undergo the existing literal expanded-term substitution.

Boolean constructors and atom positions are copied literally. Source domains are NOT inferred from the rewritten raw occurrence list. Original domain formulas are embedded as ordinary formulas at their original Boolean positions and are themselves substituted. The explicit original guarded-atom target retains every original signed domain, including zero/cancelled occurrences.

The nine frozen targets cover original row/formula embedding, the actual initial whole-block parameter invariant, expanded-matrix meaning, concrete row/Boolean substitution, exact remaining occurrences and original-name support, preservation of whole-block independence, and exact original guarded domains. This is a semantic/source-structural state closure, not a conditional global QE field or a decision oracle.

Numeric row/formula encodings and proven uniform code/effectivity are explicitly NOT targets of this packet and remain unpaid, as do actual dominant/close-case selection, source guard coverage/progress, complement elimination, and full alternating BASE. No numbered source statement is promoted by definitions or this preflight. No candidate proof was authored before the freeze.

The whole-block invariant is specifically the dominant FREE-parameter replacement interface. A close-case replacement involving another bound name must use the existing literal shifted/hyper row transformations, adapted to leave these parameter constants fixed. It cannot be moved into a supposedly independent constant by citing the whole-block theorem: that theorem explicitly requires the replacement to omit every bound name. The unconditional pointwise substitution target does not remove this separate invariant obligation.
