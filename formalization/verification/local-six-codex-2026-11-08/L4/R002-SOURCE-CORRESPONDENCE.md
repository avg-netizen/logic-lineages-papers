# Exact all-input original scheduled evaluator

The existing KernelSourceCompletion.sourceCount is actualScheduledCount (sourceBudget c t) (omega^d), with sourceBudget c t i = Phi^[i+1](t)-c. The new numeric run stores the literal original index, starts it at zero, and applies encodedMaximumPredecessor to the encoded limit part under exactly sourceBudget c t index. Initial state is the bare principal omega^d, with no compensating finite tail.

RawSplit and encodedMaximum correctness apply to every normal nonfinite state and every natural budget. ActualScheduledFirstFinite supplies the termination witness. A real Nat.rfind searches numeric finite-state tests. Its result is required to equal the original first-finite count, with source trajectory calibration through that index. Malformed starting codes return zero by an explicit guard.

The unbounded search is required Partrec plus separately proved totality and a Computable wrapper; there is no automatic primitive-recursive claim. Generic raw-step/run/budget programs are independently required computable.

The existing compensated-count implementation is a code/proof architecture template only. Its scheduler, source correspondence and tail calibration are NOT reused as the target mathematics. The source-count equality has no c+d+1<=t restriction and is intended to support evaluation of literal original finite-prefix word inputs.

No proofs or native check have been run for this packet. R001 remains first for acceptance.
