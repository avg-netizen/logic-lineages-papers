# Original ordinary observation view — literal head/base supplier

Source Fun/Copy/Stat tests inspect an original functional target head and its complete fixed base argument list. This component inspects the root of actual embed t, not a beta-normalized/currying spine: a literal application is the built-in application head with exactly function and argument as its two children; native constants (even arrow-typed or partially applied through outer app nodes) have no native base children; ranked symbols retain all original ordered arguments and duplicates. Variables and lambdas have no ordinary root view, so lambda-body head traversal is not used for these rule tests. Source original-spine scanning remains separate.

Six targets: exact root-view iff the original embedded packed term is that ordinary head/base; exact complete argumentList equality; exact declared argument type sequence; equality with existing actual plainChildren observations; actual child finite-observation membership, unchanged ports and source K type; every declared head argument type belongs to K. Membership/type provenance reuses existing source closure, but exact ordered decomposition is explicit. No target normal-form flattening or head comparison redefinition. No complete Fun/Stat/operator or comparison adequacy claim.
