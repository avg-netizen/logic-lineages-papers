# Generic finite natural full-tuple table layer

Source: paper06 def:domains, lines181–201, and the finite table filter in lem:lattices, lines203–217. This is a generic induction construction, NOT the completed type-recursive domain theorem.

Family packages computational carrier/enumeration/equality/partial order/order decision and actual restriction maps with identity/composition/monotonicity. It has NO lattice/completeness fields and no arbitrary-set supremum/infimum operation. Lower τ accepts only types with strictly smaller actual SourceArrowSuffixes.typeSize; later well-founded type recursion must construct and discharge these families, rather than assuming them as final domain premises.

Suffix τ is the actual subtype of the accepted complete nonempty right-arrow-suffix enumeration. Its ordered argument list is never flattened into independent unary applications. A tuple contains one lower-family value for every actual list position; the result is the actual lower family at that suffix's result type. Proper type-size proofs are the existing exact source suffix supplier, reused explicitly, not novel results.

At P, Raw is the already accepted full observation Bits product, paired with one actual complete tuple function for every future world Q and every actual nonempty suffix. The functions' input and output types are the supplied lower-family carriers (intended already-natural values at smaller types), not inflated unfiltered raw lower carriers.

Good is exactly:
1. each entire tuple function is monotone in the pointwise order on the full tuple;
2. for every Q⊆R, every suffix and every actual full lower tuple v, restricting the output of the Q table equals the R table applied to tuplewise restricted v.

No comparison semantics, fixed point or desired final conclusion is included in Good. No additional availability constraint is inserted: the source base-domain definition has independent availability/weak/strict bits at each future world; the availability=true condition appears later for interpreted marked states, not domain membership. Empty application is identity and introduces no extra table coordinate.

All quantifiers in Good have actual finite computational domains, and its equalities/order predicates are decidable from the supplied lower-family data. naturalFinite explicitly filters the finite raw product; enumerateNatural is executable and exhaustive. The arbitrary-set lattice structure of the bit supplier is not stored in these computational families.

rawWeaken retains all future coordinates. Targets prove identity/composition, actual preservation of both monotonicity and the full naturality equations, and pointwise monotonicity of restriction. The candidate may assemble the resulting finite ordered Family using these proofs, without adding a new oracle. SuffixCalibration and exhaustive-enumeration interfaces reuse exact existing enumeration/finite-product suppliers and are not separately claimed novel source results.
