# Actual substitution confinement and protected-binder lifting

The source finite Frame controls actual occurring types and heads, not unused ambient variables. RangeConfined therefore requires a literal syntactic replacement to have the same existing type/head confinement only when its variable's type belongs to the actual source/target type set K. Every variable encountered in a confined term has such a type by the existing typesAllowed clause. The substitution and argument-list closure targets must prove this guard is sufficient by actual syntax recursion. They do not replace the source substitution operation or assume all ambient types belong to K.

The protected scanner tracks original binders separately from free substitution values. ProtectedCompatible records concrete syntactic facts: a protected source variable is replaced by a literal protected target variable of that same type; an unprotected source variable has a replacement whose actual free variables are all unprotected. The latter uses the already calibrated literal Supported predicate, not a semantic desired conclusion. Both clauses are restricted to the same potentially occurring types. Initially all free variables are unprotected, so compatibility must be proved for every substitution, not assumed. Lifting must preserve it because the new bound variable maps literally to itself and old replacement syntax is shifted capture-avoidantly. LiftedRange has no extra binder-type-in-K premise: the here case itself supplies membership when the range condition is requested.

LiteralLift is a definitional syntax interface. Closure, protected-free provenance under shift, and lifting preservation are actual prerequisites for the future semantic substitution proof. No semantic environment is defined by an out-of-universe bottom default, and no full interpreter substitution/SourceSpecialApplication theorem is claimed. A later semantic agreement premise will concern only variables whose types are in K, leaving unused ambient assignments unconstrained. The arbitrary-family structural limitation remains unchanged.
