# Actual finite observation bit layer

Paper06 def:domains and lem:lattices, lines181–217. This component isolates the availability/weak/strict observation part, at all future contexts, before recursive full-tuple arrow tables.

Input contains the actual two original ordinary terms and their ambient/result types. Budget is the actual target lambda depth. World is a subtype of the existing finite portContexts list using the literal type listings of both inputs; WorldCalibration identifies this with ValidPorts of their exact subtype-support union. Every world retains actual typed external slot identifiers. Extends is typed-slot membership inclusion: every old slot/type pair is retained. It does not assume any semantic invariant, comparison truth, or boundedness conclusion. Ordered world representatives remain those of the accepted finite port-context family; no quotient by reordering is silently introduced.

ObservationAt is a subtype of the existing actual Observation structure, simultaneously requiring membership in the existing finite observations list, exact world identity and exact output type. Its finite enumeration first removes duplicate literal observations, using the accepted executable observation equality; it does not index duplicate list positions as independent bits. ObservationCalibration is explicitly a definitional interface, not a new semantic theorem about target generation (that is paid by finiteclosure).

At a world P, Bits contains, for every extending world Q, one Bool availability coordinate and two independent Bool-valued characteristic functions on the actual typed observations at Q. Thus it is the full bit product, not a collapsed single bit and not only the current world. At ground this is the source base layer; at arrows it is only the observation component, with full tuple tables still pending.

CompleteLattice is the genuine pointwise product/function lattice on Bool; the mathematical arbitrary-set supremum/infimum instance is noncomputable, as arbitrary predicates need not be decidable. This does not enter the algorithm: enumerateBits is an ordinary executable definition assembled from the finite input world/observation enumeration, finite Bool and finite-function products, under explicit DecidableEq Symbol. ExhaustiveEnumeration proves every actual bit value is enumerated. No finite source-size bound is assumed.

Weakening is literal future-coordinate retention along inclusion. Identity/composition and preservation of arbitrary suprema and infima, including empty families (bottom/top), are exact targets. These are the projection properties needed later for hereditary naturality. Complete lattice structure here is supplied by checked standard finite products, not assumed of the unconstructed recursive domains.

Seven scoped targets: actual world calibration; definitional observation interface; exhaustive executable enumeration; identity/composition of projection; arbitrary join/meet preservation.
