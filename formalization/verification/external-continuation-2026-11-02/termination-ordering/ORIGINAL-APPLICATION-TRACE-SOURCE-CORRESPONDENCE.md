# Literal original-spine application execution and intermediate payloads

Scoped supplier to paper06 finiteclosure. Configuration records exactly the actual `applyOriginalWith` parameters: original source and its scope/type, actual substitution environment, the full remaining argument tuple, and suffix equality. `evaluate` is the existing function. `next` copies its only recursive branch: consume one original lambda and one supplied argument, protect the binder by extending the environment, retain the original body and remaining tuple, and use the exact type transport/suffix projections. No successful-outcome or invariant guard occurs in `next` or `Execution`.

`terminal` copies all original nonrecursive branches. An original variable with leftover arguments returns NONE; an empty tuple substitutes/retags; an ordinary functional head marks and appends the full tuple; an already marked head substitutes its old extras and appends the entire remainder. The otherwise impossible lambda-with-arguments terminal branch returns NONE but is never selected by the exact execution equation, since next is then SOME. `ExactExecutionEquation` must prove all these cases against the real function.

The frame checks actual source node types/heads, actual environment images (type allowance only conditional on the variable type being in K), and the entire remaining tuple. Its variable support source predicate means precisely that each used source variable has an allowed substituted image. It does not require unused ambient variables to have allowed types/names, and no frame condition defines or restricts the trace.

Every reachable configuration is bounded, including traces eventually returning NONE. PayloadBounds includes source type, every remaining suffix type, target type, the actual wholly substituted source (a conservative container for all substituted base/extra nodes), and the actual marked-extra/full-tuple append payload (or complete tuple at other heads). Thus terminal substitution and append intermediates are included, not merely successful returned values. Actual returned terms additionally retain all bounds.

`EverySelectExecution` initializes this trace for every prior SelectAttempt without a success premise. These targets do not yet establish the guarded recursive comparison request graph, its full original-rule request coverage, or whole lem:finiteclosure. Those remain distinct obligations.
