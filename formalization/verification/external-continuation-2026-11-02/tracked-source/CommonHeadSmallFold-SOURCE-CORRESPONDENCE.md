# Common-head small-occurrence folding

Source: paper08 `thm:common`, proof lines876–883.

The finite guard list is exactly the natural numbers c with N(lambda)≤c<L, where L is recomputed from the current signed row and constant using the printed threshold. The closed numerical evaluator uses the existing actual finite-tail notation operation and actual collapse computation, with no evaluation oracle. It is calibrated for every normal notation; source branches use only the genuine domain.

Under the literal guard that occurrence i has input c, the updated signed constant is K+a_i J_lambda(c), and precisely occurrence i is deleted. The entire actual row value is preserved, genuine inputs remain genuine, and the occurrence count strictly decreases. No distinctness or nonzero restriction is imposed. An exhaustive alternative supplies either all-large inputs or a small guarded branch from the finite list.

The updated threshold is the existing threshold function applied to the updated constant and remaining row. No comparison with the old threshold is asserted: the folded closed value may be enormous. This component does not yet construct a recursive comparison formula, enumerate total preorders, translate nested layers, or assert decidability.
