# Heterogeneous filtered root transport: proof implementation and scope

Status: authored candidate; no endpoint acceptance claimed by this note. The
coordinator supplies native receipts, recursive evidence and final review.
Frozen comparator and source correspondence are unchanged.

The local spine invariant uses actual original Code-validity and successful
ArgumentEntriesRecursor extraction. It proves, by strong induction on the raw
argument code, (1) universe argument acceptance implies that each occurring
(annotation, term) entry is accepted at that annotation, and (2) original plain
ordered argument acceptance plus these entry facts implies universe argument
acceptance. Nil canonicality and child Code guards/strict tail decrease are
proved from actual constructors and guards. There is no ground0 restriction,
length surrogate, target-universe oracle or externally supplied induction step.

Actual original argument permutation yields two successful extraction lists
and their occurrence-count agreement. This transports the entry facts. The
source and target ordered type lists are independent: application order is
checked by the target plain decoder, not presumed invariant under permutation.

For the exact root endpoints, target plain typing is derived from original
primary output membership. Source universe acceptance gives admitted seed;
the accepted OriginalPrimaryTypedCarrierV2 theorem yields target admission;
the original target checker is unpacked with the same parameter and the given
packed pair. Both head signatures and their fields are queried internally.
Target W is rebuilt from actual headMove source-head membership, actual head
validity derived from target root Code-validity, actual context validity and
original selectors. Source M and unchanged numbered extras are retained.

This is ordinary/numbered root headMove transport for actual filtered-primary
endpoints. It is NOT unrestricted raw headMove preservation, nor an automatic
closure theorem for arbitrary recursive codeExchange descendants. A parent's
primary membership does not imply its child's primary membership; a future
recursive theorem must derive the required descendant plain typing from the
actual enclosing decoder and handle strict descent/edge selection. No full
paper, universe enumeration coverage or accessibility completion is asserted.
