# Candidate primary-universe proof structure

Implementation draft, pending final native closure and independent review. Frozen endpoint and original ASTs unchanged.

1. SyntaxProof and InvariantProof expose capture-free substitution/renaming and introduction/elimination for the internal three-field allAccepted invariant. Its fields are actual packed candidate/type/raw, not decoded external values.
2. EdgeSourceProof queries an actual pair decomposition of the old reached source. Old-list membership specializes allAccepted to source universe acceptance; installedFilteredEdgeUniverse then yields candidate acceptance using actual edge and target pool membership. EdgeWitnessProof obtains the old source through sourceWitness existential elimination.
3. ExpansionProof uses the literal expansionSoundness disjunction. The old branch specializes the invariant directly. The new branch extracts pool membership and genuine old-list/edge witness and invokes EdgeWitnessProof. No source or target universe premise is introduced beyond the invariant being preserved.
4. IterationDefinitions binds only runtime output in AtCount, retaining count/pool/initial/parameter/gamma/context freely. The row says actual iterate graph implies allAccepted(initial) implies allAccepted(output). IterationSyntaxProof handles those free parameters under allBlock, substitution and witness specialization. IterationProof and its proof-only Core/Step/Rows/Induction split use original internal natInduction. Zero uses actual recursion equation + graph functionality to transport membership to initial. Successor queries the actual previous iterate output, obtains its invariant from IH, recovers original expand, and uses ExpansionProof. The fixed admitted seed/pool/parameter environment is renamed into the induction step, not assumed as a recursive supplier.
5. EqualityProof transports actual paired fields and universe-checker input equality. SingletonProof derives candidate=seed from actual singleton membership, obtains type/raw equalities using both pairing graphs, and transports original seed acceptance. It never assumes syntactic field identity.
6. RunProof reconstructs the literal singleton composition used by PrimaryIteration.run and combines SingletonProof with symbolic-count IterationProof. AtPoolProof queries original countOfPool, peels the admitted primary branch and recovers actual run with original fixed pool. Proof.atSource queries that actual pool; final primaryUniverseClosure specializes allAccepted to the actual candidate pair and membership.

No semantic/native evaluation is used as an internal inference rule. No list-code equality, deduplication, arbitrary B, replaced pool/count, target success or all-reached closure supplier occurs in the final endpoint. One carrier preservation endpoint only, not a numbered theorem or global accessibility proof.
