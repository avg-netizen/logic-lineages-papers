## Relation to unpaid induction
This package abstracts the local induction hypothesis for a selected child edge.
It does not claim that the child pair is an exchange edge, that the child is
strictly smaller, or that a global induction hypothesis is available. Actual
recursive edge selection and strict descent remain separate obligations. It is
stronger than a single selected-edge congruence because it needs no exchange
premise once the explicit local child implication is supplied; it is not a new
raw exchange relation or a weakened replacement for any frozen target.
