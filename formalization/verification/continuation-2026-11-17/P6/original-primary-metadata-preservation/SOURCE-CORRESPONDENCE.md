## Exact endpoint

Q=OriginalCandidates.candidates n arity H, E=OriginalConcreteStructuralEdge.edge,
and L=SeededPrimaryPool.primary T Q E, retain one seed and unchanged parameter.

derive root-type equality AND equality of the COMPLETE original bounds code.
The bounds recursor returns (size,maxLabel), not depth, rank or just size.

No universe premise is needed: original E itself preserves type and bounds,
even though raw head permutations need not preserve positional typing. The
fixed filtered primary is retained exactly, without using target admission
or target universe success as a preservation assumption. No source=seed,
source/target validity, intermediate pool membership, bounds equality, induction

Parameter unpacking is not a public premise. Query its pair context/Gamma
internally; likewise query context/window and raw source/target node when
needed. Both observed endpoint packed fields and bounds remain independently
quantified, so functionality/injectivity must relate repeated observations.
