# Original candidate self-coverage

Source-scoped exact original Q membership for its own packed seed, arbitrary fixed head signature H. Retains actual seed/parameter pair observations, original context decoder success, actual selected types and ArrowClosed, source term-universe acceptance, and actual Q output. No seed admission, bounds/capacity, enumeration image, target acceptance or pool membership premise. Internally query actual heads and raw bounds with its size/label pair, derive original size/labels selectors and strict self-successor inequalities, then invoke existing OriginalSourceCandidatesCoverage at candidate=seed. This new caller eliminates all metadata and capacity suppliers, not a change to existing coverage.

Feeds common-Q root membership and membership-equivalent seed pools. Does not prove pool code equality, primary equivalence, edge symmetry or original global accessibility.
