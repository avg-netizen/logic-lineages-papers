# Executable validation of the actual numeric universe and canonical carrier

The Boolean universe test follows the unchanged actual auxiliary term/argument syntax and checks exactly auxTypesAllowed together with auxHeadsAllowed for the literal window. The numerical universe decoder filters the accepted typed numeric decoder by this actual Boolean test; it neither inserts a default term nor restricts unused ambient context types.

The five targets give exact term and argument universe tests, numerical decoding iff actual code equality plus InUniverse, raw-carrier validity iff an actual typed universe witness, and canonical-carrier validity iff the input is the computed representative code of some genuine universe term. Only the last requires SubtypeClosed S. Its completeness must use actual least-code attainment, primary confinement of the attained representative, and already proved representative equality; valid canonical numerals are not assumed to decode by definition.

The carrier checks are executable ordinary definitions over an explicit finite Fin n signature and actual context/type window. They do not assert a formal arithmetic formula, arithmetical representability, a rule-certificate checker, accessibility or well-foundedness. The guarded quotient and original comparison semantics remain unchanged.
