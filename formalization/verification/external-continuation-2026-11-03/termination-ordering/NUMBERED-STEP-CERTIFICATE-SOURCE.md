The finite certificate stores an allowed context path and natural numbers encoding the hole replacement and root selector. The checker focuses the actual typed source and runs the total partial-decoder functions at the returned actual hole binder context, rejecting failures and replacement-type mismatch. It uses the accepted raw root-selector checker, not the universe-validating numeric root wrapper, so no hidden hole-confinement premise is needed. It then plugs the decoded replacement into the actual returned context and compares the full target using the accepted injective packed number.

Three targets establish soundness to the actual WindowStep under the explicit Boolean-table interpretation, completeness from actual WindowStep, and separate target confinement from source InUniverse under SubtypeClosed. The first two need no Good or subtype premise. Completeness must use accepted genuine root/context decomposition, exact focus coverage and actual replacement/selector decoder roundtrips. Soundness must use focus reconstruction, actual root erasure, context lifting and packed-code injectivity. No root or context success is supplied as an external oracle.

This covers all actual guarded WindowStep rules, including allowed recursive contexts and excluding positive auxiliary application-argument reduction. It is certificate completeness, not a bounded decision procedure for existence of a certificate. Whole-certificate natural encoding, arithmetic representation, quotient accessibility and the unresolved original ordering/transitivity issue remain separate. No source comparison rule is changed.
