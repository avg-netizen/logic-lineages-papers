# Actual counted paths on least-code representatives

For the fixed finite signature, context and type/head window, QuotientEdge is witnessed by a genuine typed WindowStep from an actual InUniverse source. Its endpoints are the previously computed least class codes. The target's confinement is derived from the accepted window-step preservation theorem under SubtypeClosed S; it is not a new premise on the edge.

CountedPath is the ordinary finite edge path retaining the exact number of genuine edges: identity has zero, one edge has one, concatenation adds. PositivePath is the nonempty transitive closure. No well-foundedness, arithmetic formula or decision oracle is included in either definition.

The four targets calibrate an edge with primary motion before/after a genuine raw step, map actual restricted traces forward with their exact count, reconstruct a restricted trace backward between codes of two genuine InUniverse endpoints, and identify positive closure with positive counted paths. The backward proof must derive each intermediate representable endpoint from the actual edge witness and join it using the proved representative equality iff guarded primary equivalence; arbitrary natural numbers are not presumed valid representatives. Forward intermediate Good follows from actual boundary confinement. Both directions keep the same window/context/signature and do not require precedence transitivity or original comparison transitivity.

This is quotient path semantics only. Arithmetic definability, numeric decoding, accessibility in ID1, ordinal bounds and unrestricted original well-foundedness remain unproved here. No original rule or accepted comparison semantics is changed.
