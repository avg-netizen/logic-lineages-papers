# Typed direct-rule certificates: Put, Abs, beta and bottom

The selector has exactly four branches. Put carries its requested natural label and accepts only an ordinary root. Abs accepts only a successor-numbered root of actual arrow type, and constructs the literal openNumbered body beneath a lambda. Beta accepts exactly an auxiliary app with a literal lambda in its function position and uses the actual singleSubstitution operation. Bottom accepts precisely non-bottom sources of any actual type; the bottom source itself fails. No recursive context traversal is performed by this checker.

DirectInstance copies only these original WindowStep constructors. The first target is exact typed recognition for the specified rule selector, without source confinement. The second gives the genuine WindowStep and target confinement from initial InUniverse under explicit SubtypeClosed S, using the existing all-rule preservation theorem. Subtype closure is relevant to the newly exposed domain/codomain in Abs; no precedence property is assumed.

Select, Copy, Mul and recursive contexts are not recognized here. This is typed executable reconstruction, not a natural-number certificate decoder, full WindowStep decision, arithmetic representation or accessibility proof. The local original ordering and transitivity obstruction remain unchanged.
