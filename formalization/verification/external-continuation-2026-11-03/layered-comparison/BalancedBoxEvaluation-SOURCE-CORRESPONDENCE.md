## Explicit conversion from sparse actual support to a raw table

The only new data conversion is `finiteTable support word`. Its width `tableSize support` is `support.foldr (fun i rest => max (i + 1) rest) 0`: zero on empty support, and one beyond the greatest raw name otherwise. The table is `(List.range (tableSize support)).map (singleCoreBoxLookup support word)`. Thus a support such as `[2, 7]` is represented using raw table positions 2 and 7, with the intervening coordinates filled by the existing lookup. The word's coordinate number is never mistaken for its raw-variable name.

`ExactBoxEvaluation` explicitly includes `Computable₂ finiteTable`; this computational fact is a target requiring proof, not an inference from its ordinary `def` declaration. It also requires the table's exact length and global equality between its existing `getD`-with-one valuation and `singleCoreBoxLookup support word`, under the full guard `word.length = support.length`. The guard cannot be dropped: the lookup's absent-name `findIdx` result is `support.length`, which can address an extra word entry when the word is too long. For equal lengths that position is out of range and gives one. Every raw name in support is below the chosen width; every coordinate beyond the table is outside support and has the same default one. Empty support and empty word produce the empty table and the globally-one valuation.

`boxTable k Γ C E F word` applies this conversion to the accepted `BalancedSmallBox.sourceSupport`, which is the deduplicated actual raw support of the original pair. It does not alter the original ordered common basis, deduplicate basis expressions, introduce independent basis values, or use the support of a simplified or collected row.
