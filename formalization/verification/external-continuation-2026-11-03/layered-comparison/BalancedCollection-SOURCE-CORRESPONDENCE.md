# Balanced equal-key collection

Source: paper08 `thm:balanced`, proof of the large branch following `eq:balanced-L` (paper.tex, signed comparison row through all-cancelled remainder).

The collector uses the actual normal ordinal-head code and the complete input evaluated on the one shared basis. Its key equality is proved equivalent to the existing actual ordinal-head/input equality. It enumerates distinct keys from original occurrences, sums signed coefficients at each key, deletes zero blocks, and retains the first actual original atom as representative. It never constructs independently valued basis variables.

Exact targets retain the entire constant and outside remainder, preserve the actual row value, and identify the all-cancelled value with the original preceding-level affine remainder. Every surviving atom has original provenance, exact block coefficient and nonzero coefficient, and distinct keys. Well-formedness and genuine-head validity transport from the original row.

Absolute coefficient mass and every relevant threshold maximum are nonincreasing; the original printed balanced threshold therefore remains a valid bound. No larger replacement threshold is used. The original source-pair support remains ambient finite-exception metadata: syntactic support equality after cancellation would be false and is not claimed. Repeated or dependent shared basis values are unrestricted.

This is a collection and threshold supplier. It does not yet prove the literal preceding-level affine syntax/compiler for the remainder, finite exception formula, balanced layer compiler, quantified arithmetic decidability, or whole balanced comparison. The current semantic collector is specified on actual rows; no raw-code computability claim is inferred merely from its definition.
