# Primitive evaluation addendum to chosen-control hardness

The historical SourceControlHardnessBundle targets, proof, correspondence and freeze remain unchanged. This separate addendum pays the restricted-source evaluation step in paper09 hardness.tex lines 316–319: “Every value of a displayed source is computable: its closed heads are finite and the collapse reduces to fixed finite iteration of the primitive recursive control.”

For each fixed b, the existing checked Option source evaluator is primitive recursive. For an actual ground-output source term in an all-ground context, satisfying the recursive ground-binder/zero/successor Fragment, and a numeric input list of exactly the context length, it succeeds and its result is exactly the existing Gamma Scalar observation at rawValuation xs. No positivity is required for this evaluation statement; positive lists supply the manuscript's valuation class as a special case. Invalid raw inputs retain the existing Option failures and are not identified with source observations.

The precise collapse identity is value Gamma_b (a,c) = (Gamma_b^[a])(2*a+c)+a, including a=0 and c=0. This is an explicit input-dependent finite iteration count a. The source evaluator composes such iterations by the finite encoded syntax fold, with primitive-recursive assignment/environment construction. Thus the restricted-source upper-bound argument needs no unbounded search to compute an observation. We do not interpret “fixed finite iteration” as a single iteration count independent of source/input, nor claim such a bound.

The chosen actual blank-table enumeration and transition clock, canonical assignment policy, malformed-code distinction, and literal weak-wrapper qualifications of the original bundle remain in force.
