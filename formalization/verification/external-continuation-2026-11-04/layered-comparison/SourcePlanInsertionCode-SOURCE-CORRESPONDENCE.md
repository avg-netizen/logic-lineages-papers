# Binder-aware canonical Plan insertion

This is a syntactic implementation bridge for paper09 hardness.tex lines 294–314 and its accepted literal conjunction Plan, not a source theorem promotion. It uses the existing canonical List Instruction representation and the actual BinaryPlan.renamePlan, without changing syntax or denotation.

ExactProtectedRecursion proves the all-raw scan's nil/cons equations. An existential tag 4 increases protected depth by one for the remaining spine; all other instructions preserve depth. Numeric port zero remains zero. Positive port p is unchanged when p-1 is protected and otherwise increases by count. Gate instructions do not bind source coordinates: their nine compiler-generated witnesses belong to the later compilation stage, not this renaming scan.

ExactSupportedInsertion calibrates precisely to ContextInsertionCode.insertion Θ Δ Γ on a supported Plan in context Θ++Γ. Source-equation payloads use sourceCode at protected depth Θ.length, which separately handles lambdas inside each actual source term. Eq/add/one port payloads use portInsert. Recursive existential bodies extend Θ by ground, matching the actual lifted renaming. Sort is excluded by Supported; raw unknown tags are preserved inertly. Filler slots are retained, and canonical typed instructions match exactly.

UniformPrimitiveRecursive covers port transformation, instruction transformation and whole finite scan on all raw naturals/lists with standard Primcodable products. The scan is a list fold with reversed output, not unbounded execution. No malformed typedness, arbitrary renaming table, scaling or binary constructor, (b,e)-to-spine map, scalar Nat wrapper, size/runtime or full hardness claim is made.
