# Internal evaluator result-content boundary

The checked concrete completion invariant controls admissibility, the original window coordinate, global branching, and agenda potential. It proves that the actual bounded run has empty pending work. It deliberately does not constrain the result stack or require stored return counts to have been generated by a corresponding visit. Consequently empty work alone is not a correctness theorem for the returned hereditary observation.

Existing internal local suppliers include exact restored term-return laws for zero/one/two children, actual reverse deletion-row and child-slot partition laws, and actual supported return effects. They take the literal completed result segment as input, rather than establish its provenance through an entire execution. Native Expected/settled-observer proofs are not internal reflection principles.

The new OriginalInternalReturnRootProjection target inverts an actual supported term return and actual output pair/cons geometry to recover the rootObservation R graph of the returned value's first coordinate. It requires neither child-slot correctness nor deletion-row correctness. Its local scope does not identify the last return as the root return, nor establish full evaluator fixed-point or hereditary-view correctness. Compiler status is recorded separately in the gate receipts.

A full internal content proof needs a protected result-suffix/subtree execution relation. A visit must retain its actual child/deletion counters, and completed children must push their values in reverse schedule order above the protected suffix. Return uses the existing exact partition lemmas to reconstruct the parent observation and restore that suffix. Strong induction can reuse actual child-weight decrease and fixed-global-branching budget bounds; contextuality and stopped-state padding must be proved for actual run graphs, not imported from native semantic execution. Administrative argument-list nodes must preserve the semantic observation level.
