**Not part of the printed theorem and not claimed by the comparator** (consistent with each other):
- quantifier alternation or free parameters (the paper says so explicitly in arithmetic.tex §"Two checks");
- running time;
- uniformity of one decider in `b`.

## Conclusion

The comparator states the printed theorem in the paper's own flattened matrix language. Every phrase is carried literally, including congruences, signs, arbitrary Boolean structure, arbitrary heads below ε₀ with the λ+k absorption, true gate domains, and both controls.

It is a restriction only in three already-printed conventions. The matrix is linear in circuit nodes (`PlainPreparedFormula`). Universal blocks range over successful runs. Correctness is claimed only on encodings of topological circuits, where the answer is never `none`. The phrase "the procedure preserves sharing" is honoured by the statement's form but is not proved as a separate property.

Verdict: **the printed theorem**, modulo those named conventions. I see no gap that would block promotion of `thm:arithmetic` once `ClosedBlockDecision` is unconditional.
