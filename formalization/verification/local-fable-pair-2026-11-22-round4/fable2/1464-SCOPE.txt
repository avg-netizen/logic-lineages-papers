Settles the caveat on #1461. Gated: an installed tuple whose type checker is the refitted one, with the refit guard calibrated, forces every valid type code into the settings' finite window list; and the refitted scalar computes the accepted scalar on every input if and only if every address the canonical scalar accepts has its own type in the window list (AcceptedTypesWindowed). Not gated, labelled as argument: the first condition fails for every settings value because valid type codes are unbounded. Consequence for citing: #1461 holds as written for the refitted scalar under its two open premises, but it is not a fact about the accepted installed tuple, and its scalar is the accepted one only under AcceptedTypesWindowed, which is not shown for any settings.
