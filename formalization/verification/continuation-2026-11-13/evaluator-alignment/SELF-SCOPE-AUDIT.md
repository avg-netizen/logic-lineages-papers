## Why these are source constructors, not merely output tags

SourceTags opens actual packed/source coordinates and eliminates the original
source checker to TermAccepted. TermTags excludes tags 6, 7, and unknown tags
using the original rejection theorem. Thus the six branch split is paid
internally. TagRecover relates the actual input tag to the actual stored
root-observation tag; it does not equate them definitionally.

Types uses literal branch pair projections. The lambda case additionally opens
source-admitted lambda constructor fields and reconstructs the actual arrow
from domain/codomain using the original cons-tail graph. This pays the
otherwise invalid inference from arbitrary lambda-shaped raw selectors to a
well-formed packed arrow type. The actual lambda child parameter is built
from the same original parameter projections and shared domain, then compared
by original cons/pair functionality.

All root observations are obtained from the SAME original evaluator's
source-only layer law and actual projections of one common evaluator output.
Neither evaluator nor source AST was changed.
