# HB2 source correspondence audit

The accepted target uses `GorbowPublishedLobReduction.hb2` directly, not a replacement implication law. Its literal definition is `prD(sigma → tau) → (prD sigma → prD tau)` for arbitrary external closed sentences. `prD` itself remains the original binary-code term for `rho → sigma`; it is not definitionally replaced by a convenient raw checker predicate.

`CodingProof.literalPrD` discharges the fixed-code term equivalence inside the SAME actual source S, from its retained literal coding calibration. `CodingProof.certifiedDistribution` constructs the actual logical S-scheme derivation for `(rho → (sigma → tau)) → ((rho → sigma) → (rho → tau))` and applies existing constructive S-proof certification. The latter is used only on this actual closed derivation, not on a hypothetical local assumption.

`PackageProof.hb2Package` then combines two genuine internal quoted MP laws, one fixed certified distribution proof and three code equivalences. The two prD assumptions remain local Hilbert hypotheses until discharged. The quoted MP laws handle their unbounded existential fuel and certificate witnesses internally. No extraction of external proofs from those assumptions is performed.

`Proof.sameSourceHB2` retains identical source witnesses from the accepted saturated-source MP package, including the original producer installation. It does not replace rho, the enumerating code, pF, pR, or the checker while preserving old facts by fiat. Since S is the base of D, proof placement in S is stronger than required placement in D for this schema alone.

This audit does not supply HB3. Internal computation quotation remains unpaid, as detailed in HB3-REMAINING.md. No statement-count change follows from this supporting package alone.
