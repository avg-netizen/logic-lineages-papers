## Exact contract and retained row

Its explicit hypotheses are numeric list length, original `tagVisits`, bounded `AllComplete`, bounded `AllContent`, the actual map of `FramedContentDefinitions.contentProgram R` over jobs, and the actual reverse graph from that same forward row to supplied `produced`. It concludes `Counted R tagged produced`, not an existentially substituted row of equal length.

`Counted` existentially quantifies only the run count. The supplied produced row is outside that existential; both row and count precede all arbitrary agenda suffix/result backgrounds in `Runtime/PrefixFrameDefinitions.PrefixFrame`. Its run is the unchanged `OriginalHereditaryRuntimeIterationDefinitions.run R`; input is `(tagged ++ suffix, old)` and output is `(suffix, produced ++ old)`, using literal numeric graph formulas. Preservation concerns the old suffix, not equality of the entire result stack with old.

## Induction and actual content preservation

`ContentVisitsProof.allRows` uses internal arithmetic `natInduction` at symbolic `size`, universally quantifying jobs/tagged/forward/produced. It is not native list reflection. The zero case derives all supplied rows equal to nil using length, map and reverse functionality, then transports the identity prefix frame.

In `ContentVisitsStepProof`, head completion is extracted from `AllComplete`; its actual count and value are eliminated from the original completion formula. `AllContent` is applied to that exact framed witness, yielding the same evaluator-role observation graph for that actual value. The tail completion/content universals are derived by successor lookup and strict index bound. Tail tag/map/reverse outputs are queried internally, and the induction hypothesis applies to precisely those outputs.

`ContentVisitsConsCore.atValues` forms the singleton head-value row, appends it after the tail-produced row, and proves this append equals the originally supplied produced row by the actual reverse-cons theorem and graph functionality. Prefix composition uses that transported append graph, giving count headCount + tailCount and the original supplied produced row. Thus the reverse-map content is retained through induction, not replaced by a length-only witness.

## Conditional boundary

`contentProgram R` is exactly `Context.ChildContentDefinitions.observationFromJob (OriginalHereditaryEvaluatorDefinitions.evaluator R)`, not a replacement evaluator. `AllContent` quantifies all actual framed count/value witnesses at each bounded lookup; it does not assert completion existence. Existence is separately assumed in `AllComplete`. Neither assumption is discharged from source Job admission in this packet. There is no circular admission hidden as a derived fact: these are visible conditional suppliers that a subsequent smaller-job argument must establish.

The theorem supplies mapped visit-prefix content useful for role-one integration; it is not the final Job-plus-Framed content theorem, does not itself prove every job's semantic content, and does not discharge return-tick/deletion-row correctness or full I/C.
