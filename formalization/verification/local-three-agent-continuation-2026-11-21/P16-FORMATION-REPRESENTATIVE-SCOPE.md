# Transport to the function representative under one typing rule

The single fixed-argument typing rule sends an actual arrow-window member to its actual codomain application window. Together with the measured function-edge law this preserves a successful application value when replacing the function by its selected representative. Window and cover reports at individual exchange edges are derived internally.
