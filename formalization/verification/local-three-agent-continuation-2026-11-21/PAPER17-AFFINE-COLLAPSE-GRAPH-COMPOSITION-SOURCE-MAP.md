The source requires a natural output at each affine node and the original affordability bound at each unshifted fixed-head collapse node. It uses a single natural coordinate for a node wherever the value is referenced, and keeps the graph equations in conjunction outside a negated output test. The actual two-node graph reads the affine expression at the original valuation, writes one fresh natural name, and reads that same name as the collapse input. The collapse result is written to a second fresh name. Each original name retains its value. The exact ordered pair exists uniquely precisely when the signed affine value is nonnegative and the original unshifted head guard holds at that natural value.
