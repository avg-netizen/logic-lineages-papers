# Paper 17: literal abstraction partials with a supplied policy program

The indexed program evaluates the actual abstraction partial coordinates in increasing order for exactly `[0,m+1)`. Each call passes the same code, original input level, the coordinate's own grade, and the original zero-defaulted body coordinate. The original refusing collector then consumes the returned option list. If an eagerly evaluated call diverges, there is no totality claim; a terminating returned refusal is an ordinary option value.

The exactness theorem is conditional on the supplied partial backend implementing all original `PolicyPartial.run` calls at the same index, including returned refusal; with that hypothesis the complete result is exactly `PolicyAbstraction.partialsCode`. The joint partial-recursiveness theorem separately assumes the backend is jointly partial recursive. The receipt does not itself construct that backend or check the complete abstraction body.
