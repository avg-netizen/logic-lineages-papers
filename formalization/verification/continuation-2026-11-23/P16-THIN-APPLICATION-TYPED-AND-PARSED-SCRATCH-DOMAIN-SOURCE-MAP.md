# Paper 16: narrow typed and parsed-scratch application-domain suppliers

ThinApplicationDomain is an exact same-statement recut of the generic
first domain root. It does not import the historical measured class
target, because that first domain result works for every X. It derives
the actual application least from actual same-Wp argument and function
windows and distinct true TV/refit guards, without selecting X.

ParsedScratchDomain is a source recut of the already-checked private
leastAtActualContext proof in CombinedRestrictedWrapperReportProof. It
uses the very same parsed original context and actual own member of
the same physical scratch to obtain actual original hasLeast at an
arbitrary W and X. It does not require or infer W acceptance. This
is a supplier for later application cover-domain proofs without
raw function typing. No nominal equality to the private declaration
is needed and no existing source is changed.
