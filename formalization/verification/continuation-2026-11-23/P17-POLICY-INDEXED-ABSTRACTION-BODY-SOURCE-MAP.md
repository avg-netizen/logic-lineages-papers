# Paper 17: the original body of indexed abstraction

The body first uses the original coordinate partials, and services an actual ordered result prefix. A zero scalar repetition returns literal zero without calling the policy; a positive repetition sends the original count minus one and replicated terms. A positive body coordinate makes the original abstraction macro call with the indexed, zero-defaulted partial inputs; the other branch returns the original head closure. The original cutoff, finishing constructor and refusal behavior are preserved.

The exact result becomes the old result at any implementing index. Complete abstraction is exact given the calibrated indexed partial backend, and jointly partial recursive given a jointly partial-recursive backend. These are not by themselves a concrete assignment or source-code compiler.
