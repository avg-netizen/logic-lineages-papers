**Source boundary.** Paper 16, `sections/ordinals.tex` 145–148, requires
occurrence-level origins for the two components. The original
`NumberedWindowDirectAlgorithm.directLists` uses ordered append followed
by multiplicity-sensitive permutation; this packet retains the actual
scratch reports and selected literal count/permutation graph at one.
The exact working interface is `NumberedWindowInternalOriginKeptSplitTargets.evidence`
and its four original `piece` fields. No result about the old existential
checker, target insertion allocation, full origin split, or strict descent.

- `...OriginKeptLeftRelocationLocalProof.exact_OriginalKeptLeftSource`
  takes actual old source slot 4, a genuine comparison of slot 1 with
  the supplied head-cons of shorter left removed, and both actual new
  append reports. Original common prefix (#1607), exact cons shift and
  observer symmetry/transitivity produce the updated actual source join.
- `...LocalProof.exact_OriginalKeptLeftKeep` takes the actual outer
  target cons, new left kept cons and new kept joined cons. Actual
  `consBackward` constructs the new ordered append from the old slot 6
  append. Same head congruence (#1608) preserves count.
- `...OriginKeptLeftRelocationProof.exact_OriginalKeptLeftRemove`
  reconstructs the extended left removed join by actual `consBackward`,
  applies original common **right** suffix to the real comparison of
  slot 1 with the removed cons, and cancels one same head from the
  resulting real comparison of anchored actual cons.
- `...Proof.exact_OriginalKeptSplitRelocateLeft` updates the old
  `evidence left right Ktail extra` with the ordered eight witnesses
  `[newLeftKept, shortLeftRemoved, oldRightKept, oldRightRemoved,
     newLeftJoin, oldRightJoin, newKeptJoin, newRemovedJoin]`.
  Actual reports specify `extra = cons(head,removed)` and
  `kept = cons(head,Ktail)` at the literal tape level; the right
  source remains exactly the old report. Every new chosen append and
  cons used but not generated by the local rules is an explicit
  genuine graph input. No claim that a left split exists at every
  input: the actual left whole erase selection, total graph output
  elimination, right symmetry and final existential packaging are
  separate. Duplicate occurrences are never collapsed or counted as
  distinct keys by equality alone.
