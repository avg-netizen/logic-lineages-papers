# P16 actual selected application address: scalar from held fixed value

Source-only support for Paper 16 sections/ordinals.tex 113–127.
The scalar is the unchanged literal thin addressScalar cv tv W least.
It independently checks original context/type validity, W at the
selected k, and the actual least fixed point on k. None is inferred
from the raw auxiliary input shape.

* SparseAddressScalarFromFixedProof builds the real scalar program
  graph from the checked actual original three-field address
  selectors, positive cv/tv, the actual W(k), and the actual fixed
  least(ctx,ty,k)=some(k). Its output equation variant keeps the same
  observed y and derives the selectors using original
  fromAddressEquation, not an arbitrary new address.
* SparseSelectedLeastScalarProof uses paid retained predecessor and
  exact_SelectedWindowFromRetained to discharge selected W(k) from
  genuine W(seed) and the exact successful original packed least.
  The exact W/X/C/settings and arithmetic context are retained. It
  still requires the original fixed-point report at k, not another
  caller's equality or just the successful call at the seed.
* For the older exact literal coveredWindow/guardedExchange paired
  tuple, SparseRoundLeastChecks.exact_CoveredLeastIdempotent is an
  original proof of this fixed point. Its broad legacy closure reaches
  Mathlib.Logic.Hydra and Mathlib.Tactic.Linarith, and it is not a
  proof for the distinct thin measured/window selection by mere
  numeric equality. It is not imported into these thin roots.

No scalar result on an arbitrary apparently shape-refined acceptance,
no automatic original application seed W, no changed production
program or stronger equality of arbitrary least programs. On the
genuine shaped/selected packet newly open, use the same y address
equation/selected packed k and pay those real reports. In particular
mere equality of a raw seed tag and a selected tag is insufficient.
