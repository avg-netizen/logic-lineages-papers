# Open transport on actual rank-tested exchange rounds

Rank-tested packed edges project to the actual ordinary packed edge.
The original guarded pair, cover comparison and typed windows remain
in the proof. The rank test can be put back from two actual reports
with the same output, on both tapes of the guarded pair.

A real ranked function edge preserves its source rank report. The
physical tag-six parent has rank zero when the function does and
increments a positive function rank. Both parent rank reports are
built by the actual memo program rather than assumed. With the
original typed parent windows this gives the genuine ranked parent
edge through a fixed argument, at every actual source rank.

The physical count and the paired-closure theorem then transport a
held application least along all original rank-tested exchange rounds.
The representative theorem uses the actual function least and the
source rank report as inputs, without requiring an externally
prescribed edge list or equality of the raw representatives. This
concerns the exchange and least subprograms, not the full
rank-partitioned address positive-path and computability wrapper.
