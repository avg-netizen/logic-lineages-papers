# Paper 16 (L): actual finite head occurrence elimination

Given an actual open membership report on the fixed physical finite
declaration tape, use the original scratch cons membership law to
expose equality of the same actual selected head to one of the
tape's literal declaration codes. Only the known finite tape's
constructor graph uses the checked closed numeral equations; the
selected head, goal, and whole proof context remain open. No
reflecting numeric truth of membership, external choice of a head,
or class-rank calculation is used. Finite declaration cases help
the outer (L) head-class proof, but do not prove its ranking or
progress.

Exact gate NumberedWindowInternalConstructorHeadFiniteProof, alias
exact_OpenConstructorHeadFiniteCases. Input is the exact declared
scratch-list numeral and its actual membership report. Bridging
an arbitrary admitted term to that report is separate.
