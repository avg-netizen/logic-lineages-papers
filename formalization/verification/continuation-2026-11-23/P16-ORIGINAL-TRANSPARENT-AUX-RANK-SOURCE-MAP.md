# Paper 16: transparent original neutral rank on literal auxiliary rows

The existing `NumberedWindowNeutralSpineRankAlgorithm` reads only
the earlier function-rank entry in its literal tag-six row. The exact
result is zero when that earlier value is zero, and its successor
otherwise. No type-admission or argument-rank premise is present in that
original numerical algorithm.

* `NumberedWindowInternalTransparentAuxRankTargets`: construct one new
  physical scratch selector. Its update branches on the original four-field
  tag-six test and the actual function-only earlier test. The body reads the
  function rank from the same prior table, takes zero to zero, and otherwise
  returns its successor. Every other row calls the supplied original
  rank program. No argument-rank lookup is performed.
* `NumberedWindowInternalTransparentAuxRankNumericProof`: on every real
  original tag-six decoding, prove the exact numeric source equation and
  zero iff for the raw parent and function. For all original inputs,
  prove the new physical selector computes original `rawRank` whenever
  the supplied original fallback does. Induct on the actual selected
  scratch recursion, so the earlier memo values are derived, not assumed
  on the final public theorem.
* `NumberedWindowInternalTransparentAuxRankOpenZeroProof`: from a genuine
  open zero report for the same physical function selector, produce a
  zero report for the literal parent in the same body/context. Open the
  real prior table under its own binder, align the same child *function*
  earlier lookup, introduce both actual branch rows, and install the
  selector successor. This is only the forward zero direction in the
  object calculus and never reflects numerical equality or the fallback
  program's open reports.

No changes to measured exchange, raw validator, zero-rank path evaluator,
or production selector choice. The other agent may subsequently use this
transparent program in a fresh selection.
