# Paper 16 (L): eliminate the actual ordinary versus finite constructor headers

In the original arithmetic calculus, an actual constructor-header
disjunction opens either original tag 4 with exactly two fields
(head, base) or original tag 5 with exactly five fields (head, output
type, finite label, base, extras). Each branch receives the same
raw term's genuine ordered field reports and literal sparse packing
equation. The ordinary header supplies no finite numeral or
invented output/extras fields.

Exact gate NumberedWindowInternalConstructorLexHeaderProof, alias
exact_OpenConstructorLexHeaderCases. The positive constructor
header disjunction is an explicit premise. Admission, type and packed
argument parsing, and particular reduct-family progress proofs are
separate.
