# Paper 16: actual two mapped tails for the chosen projected branch

On a supplied complementary filter branch, the retained side is the
literal old row cons and the other is its actual tail by object equality.
The same successful physical projection on the old input and retained
side exposes corresponding physical projected cons cells at the same
actual head target. The unselected side's physical map is transported
to its actual tail. Then the two real side tail maps and the old input
tail map instantiate the inherited simultaneous count invariant at
their literal append output.

Exact gate `LogicLineages.PersistentMarking.NumberedWindowInternalProjectedCountBranchProof`,
alias `exact_OpenProjectedCountBranch`. The one-head side arithmetic
is explicitly supplied by a small generic exact interface; the two
concrete side cases discharge it separately. This does not yet run
the whole induction or weaken counting to membership.
