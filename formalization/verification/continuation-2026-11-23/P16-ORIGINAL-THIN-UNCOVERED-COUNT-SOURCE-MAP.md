# Physical occurrence count used for original sparse round exhaustion

The literal original list recursion counts uncovered occurrences in the
actual candidate vertex tape, using the same actual scratch membership
answer at [reached,head]. The empty count is zero, a covered occurrence
keeps the tail count, and an uncovered occurrence adds one. No set or
duplicate-elimination proxy is substituted. The initial opened membership
and true miss reports live in the original arbitrary arithmetic ambient.
These formula leaves do not yet prove strict decrease or finite stability.
