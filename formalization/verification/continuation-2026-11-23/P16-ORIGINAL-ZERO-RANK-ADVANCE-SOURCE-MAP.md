# Original rank-zero advance and parameterized certificate fold

The checked object filter applies the genuine open rank graph to the result of
the original optional physical advance. Success keeps exactly the original
witness and certifies rank zero at the same raw output, in the same ambient.

The original positive-certificate program is factored at its actual Program4
advance. Specializing the parameter to the original advance gives the original
syntax with the original fuel, cursor, and witness unchanged. This is not an
open rank-zero completeness or application-congruence theorem.
