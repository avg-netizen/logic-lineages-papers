# P16: preserve an actual positive edge at an open classified auxiliary

Paper 16, [ordinals.tex](../../../16-persistent-marking-termination-ordering/sections/ordinals.tex) 112–139. A variable open canonical address need not retain the literal input syntax before canonicalization. Use a report about its **selected least field**, and the checked projection to the actual tag-six head. This excludes the free and bottom branches of the actual selected refined checker.

The old accepted path retains every witness and endpoint. No derivation is moved to a different inductive body: the proof takes place in one unchanged arbitrary ambient ID1 body, in particular the refined literal body itself. This does not assert that every original application has an auxiliary least field, that the raw input and least fields are equal, or that the general ForwardRule holds.
