# Indexed ranked recursion: literal graph sweep

The shared policy key is passed unchanged to each layer; each pass uses exactly the old ranked graph's ordered frontier and immediately preceding matrix. Outer partiality means a layer did not return, not that one local option suppressed a row. The original root extracts the same position zero.

This packet gives jointly partial-recursive sweep/root from a jointly partial-recursive finite layer, and full graph/root agreement under a supplied exact (total) per-layer calibration. The actual policy-indexed finite row traversal, partial, and assignment are not supplied by this packet. No numbered theorem.
