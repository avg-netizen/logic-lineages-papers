# Indexed ranked recursion: concrete finite layer

One pass consumes the original finite frontier in its exact order. It passes the same supplied key to each node assembler, with ordered child lookups on the unchanged previous rank matrix. A terminating optional omission leaves the prefix unchanged; a genuinely divergent assembler is not translated into an omission.

The raw finite traversal is jointly partially recursive given a jointly partially recursive indexed assembler and the original primitive child lookup program. Every total calibrated assembler produces exactly the original filterMap table, enabling the independent ranked graph bridge. No indexed typed assembler, full assignment, or numbered theorem is claimed.
