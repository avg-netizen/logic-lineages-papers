zero, the primitive class at one, and a configured ranked declaration
at its actual lookup row index plus two. The literal lookup equation
bounds any successful row index by the actual declaration-table
length; all successful original head ranks are strictly below length
plus two. An additional exact alias proves the corresponding original
arithmetical strict inequality for the rank numeral using only checked
closed numeral equations and the actual less-than rule.
