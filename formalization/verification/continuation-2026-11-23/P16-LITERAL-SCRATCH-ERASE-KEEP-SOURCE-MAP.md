# Literal original scratch eraser retains unmatched heads
At the same physical object eraser, both actual keep cases recons the
unchanged original head on the exact residual tail: one when the
tail flag is already one, and one when the tail flag is zero and the
head is provably unequal. The exact constructor rule composes
these actual steps into the same original cons-state report. This is
not yet a symbolic membership-to-found or full count-effect theorem.
