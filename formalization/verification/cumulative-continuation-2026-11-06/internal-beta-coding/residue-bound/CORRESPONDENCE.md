# Frozen internal residue-scale supplier

The scale predecessor is literally b*(k+1)+k, so its successor is internally equal to (b+1)*(k+1). ActualScaleMultiples preserves the original bounded difference-divisibility formula under this enlargement. ActualResidueBound derives r < 1+(i+1)*B from r<k for all original object terms i, r, with B the successor scale. Both are arbitrary-context derivations in the existing source calculus, with no semantic interpretation or extra arithmetic premise. These are supporting suppliers only, not full beta coding.
