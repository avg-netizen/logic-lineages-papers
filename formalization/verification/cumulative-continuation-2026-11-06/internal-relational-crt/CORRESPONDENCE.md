# Frozen relational bounded CRT supplier

ActualRelationalCRT generalizes the separately accepted term-defined bounded CRT without editing that target or any accepted source. For arbitrary original parameters alpha, any object-language bound n, any positive term-defined modulus family succ(t(i)), and any original formula R(i,r), it proves:

[triangular bounded pairwise coprimality of the moduli at i<j<n AND for every i<n there exists r with R(i,r)] implies there exists one shared c such that for every i<n there exists r with R(i,r) AND congruent(c,r,succ(t(i))).

The original formula R is unrestricted and is not assumed functional. Its first distinguished free variable is the index, its second is the residue, and every alpha parameter remains free. The one code c is bound before the bounded universal; residue witnesses are local to each index. All original congruence, strict-order and coprimality formulas are reused literally. No index at or above n is constrained. The bound is an object term, not an external finite length.

The proof must use genuine object-calculus induction and existential witness elimination. The step chooses a witness only for the new index and uses binary CRT with a coprime positive common multiple of old moduli. Old existential residue witnesses are preserved through congruence-under-divisor transport. No semantic Nat reflection, choice-sequence oracle, new premise, added axiom, or weakening of the target is allowed.

This is an internal arithmetic/coding supplier, not a whole coding or public-paper theorem. Definitions and target are frozen before proof authoring; target-first compilation is required.
