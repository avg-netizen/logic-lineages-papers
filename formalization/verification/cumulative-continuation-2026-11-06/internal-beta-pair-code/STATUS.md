# Internal coding of two arbitrary beta entries

For arbitrary original ordinary terms x,y and any fixed positive body,
the unchanged calculus now proves a concrete code for the two-entry sequence
[x,y], using exactly the original beta formula at indices zero and one.

The second code component is B=x+y. The first is A=(4y+1)*(B+1)+x.
The explicit quotient witnesses are 4y+1 and 2y+1; the strict-bound witnesses
are y and 2x+y. A separate exact theorem existentially quantifies the two
code components using the original finite existential binder block.

Both main exact aliases use only propext, Classical.choice and Quot.sound.
Four arithmetic supplier aliases use only propext and Quot.sound. Focused
gate closure has 762 source-matched modules; arithmetic aliases have their
separate retained receipt. Peak cited RSS is 1,226,832 KiB. Limits remain
2,048 MiB heap, 1,536 MiB RSS, 2,048 MiB free minimum and one thread.
Final proof logs are warning-free; no full-root or remote-CI claim.

Main failed candidates only lacked direct imports or an existing namespace.
Supplier failures and exact generated additive proof trees are retained.
The finite generator emits actual original arithmetic derivations from
associativity/commutativity/congruence; it does not reflect semantic arithmetic
truth. Frozen main and corrected supplier targets passed before proof
authoring, and no original target was weakened.

This is two-entry coding, not arbitrary finite-sequence coding or extension
of an existing variable-length code. Those, general primitive recursion,
C_tau closure, accessibility and full ID1 remain open. No numbered promotion:
