# Frozen bounded-family target

ActualBoundedCoprimeMultiple quantifies an arbitrary base type of object variables, arbitrary object terms m and n, and arbitrary object term t with one distinguished index variable. The positive modulus family is exactly M(i)=succ(t(i)). The antecedent is the literal bounded universal asserting the existing actual positive-common-divisor coprime formula for succ(m) and M(i), for every i<n. The conclusion existentially quantifies a predecessor p, requiring coprime(succ(m),succ(p)) and M(i)|succ(p) for every i<n.

The index bound is an object term, not a metatheoretic natural. The proof must use object-calculus PA induction. No semantic Nat reflection, witness oracle, certificate-predicate replacement, or new hypothesis is allowed. This is a supplier for bounded CRT, not the whole CRT theorem or paper completion.
