# Papers on differentiation, knowledge and computation

These five explanatory manuscripts present separate results from the research programme. Each includes its definitions, local proofs, bibliography, examples, TeX source and local build support. They do not require the private research repository or its problem labels. The existing papers remain separate publications.

| Paper | Central result | Relation to the source problem |
|---|---|---|
| [11 — Hyperreal differentiation](11-hyperreal-differentiation-domain/README.md) · [PDF](11-hyperreal-differentiation-domain/paper.pdf) | For every admissible additive idempotent ultrafilter near zero, the derivative domain is proper. A bounded positive infinitesimal class has every representative discontinuous on a large set. | Full answer to Alexander–Dawson's proper/full question following Corollary 10; no comparison of actual domains for distinct ultrafilters. |
| [12 — Common-knowledge necessitation](12-common-knowledge-necessitation/README.md) · [PDF](12-common-knowledge-necessitation/paper.pdf) | A truth-free KT theorem has its common-knowledge assertion provably false. Exact selector classification and direct consistency proofs explain the counterexample. | Negative answer to the unrestricted full-language rule in Gorbow's published question, with the stated PA(L) base. |
| [13 — RL transformations](13-reinforcement-learning-transformations/README.md) · [PDF](13-reinforcement-learning-transformations/paper.pdf) | Complete deterministic/stochastic four-framework classification, including the singleton-action case. | Full classification under the current same-environment ranking definition; computable or injective conversion and stronger contracts remain separate. |
| [14 — Prediction-measure complexity](14-complexity-of-prediction-measures/README.md) · [PDF](14-complexity-of-prediction-measures/paper.pdf) | Exact third-jump degree for the original measure and a canonical all-total-function variant; the latter has only finite values. | Answers specified complexity questions and a precise instance of the conjectured oracle increase, with explicit machine and enumeration contracts. Other variants remain open here. |
| [15 — Differential-field constraints](15-differential-field-constraint-decisions/README.md) · [PDF](15-differential-field-constraint-decisions/paper.pdf) | Exact first-order and independent-spectrum constrained-pair decisions over the rational constants, with an unbounded-order cyclotomic family. | Restricted input classes of the original predicate. The full constraint set is not decided; attribution of the explicit criteria remains provisional. |

The papers can be read in any order. None imports a result from another manuscript in this collection. The RL paper credits the earlier public counterexample note while including every argument it uses. The differential-field manuscript is included as a restricted-decision account whose novelty is less certain; classical ingredients are explicitly credited.

The substantive proof accounts are distinct from their build checks. These are AI-assisted hand-proof manuscripts, with imported hand reviews and a new author consistency pass, not independently certified mathematical publications. The verification files report compilation, references, fonts, file integrity and sampled layout checks. They do not certify the infinite mathematical claims or establish historical priority.

To build one paper, run `python3 build_pdf.py` in its directory. Tectonic uses cached resources by default; `--online` permits fetching missing TeX resources on a new installation. A pdfLaTeX installation is an alternative. Every local preamble selects Computer Modern.

The aggregate [verification record](FIVE-PAPER-VERIFICATION.json) gives the exact source and PDF hashes, pages, statement counts and isolated-build results. Each directory also contains a human-readable verification note and a source guide. No source-paper PDFs, private proofs or agent transcripts are dependencies.
