# Archived comparison editions

These six superseded editions (05–10) were archived on 18 November 2026 at
the owner’s request. Current reading is papers 16–20 and the
[resolution guide](../../COMPARISON-RESOLUTION-GUIDE.md).

All manuscript/PDF/source-repair/status bytes are preserved. MANIFEST.json
records every archived file’s SHA-256 and size. Historical source paths remain
as compatibility symlinks so frozen formalization source references, tools and
relative links can continue to resolve. No theorem or counterexample was deleted.
The old proof sources and TARGETS.json remain a historical register, not proof
of the new manuscripts.

Archived mathematical relative links that point to other paper entry points
can also be followed through the compatibility paths at repository root.
