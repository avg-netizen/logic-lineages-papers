# Equality and universal comparison of positive exponential terms

[Full paper (PDF)](paper.pdf) · [Canonical TeX](paper.tex) · [Source guide](SOURCES.md) · [Checks](VERIFICATION.md)

For positive integer terms generated by `1`, independent variables, addition and `E(f,g) = 2^f g`, universal strict and weak comparison are Pi-zero-one complete at exponential depth two. Extensional equality is decidable with any finite number of variables, and universal comparison is decidable with one independent variable at arbitrary finite depth.

The paper explains the connection with Wilken–Weiermann's effectiveness conjecture following Definition 2.8, including hardness on bounded two-component source vectors. It does not assert that those hard vectors occur as assignments of actual Gödel T terms. The number of independent variables in the hardness reduction grows with its input. “Unary” in this paper simply means one independent numerical input.
